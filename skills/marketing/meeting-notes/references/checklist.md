# K-패션 품평회 노트 / 회의록 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 헤더에 크럼(브랜드/시즌/회의 종류) + H1 + 일시·장소·샘플(또는 의제)·작성자 4개 메타 모두 표기
- [ ] 참석자 아바타 행에 **한국 패션기업 직책** 명시 (대표 / 디자인실장 / MD실장 / 수석 디자이너 / 마케팅실장 / 생산실장 등)
- [ ] 참석자 아바타는 직책별 컬러 그라디언트 사용 (대표 블루 / 디자인실장 핑크 / MD실장 옐로 / 마케팅실장 오렌지 / 생산실장 그린)
- [ ] **결석자**가 명시됨 (`<span class="away">결석 — XXX (회의록 사후 송부)</span>`)
- [ ] **아젠다 4~6개** — 각 항목에 체크박스 + 제목 + 짧은 설명(`<small>`) + 할당 시간
- [ ] 결정 사항 패널이 액센트 좌측 보더로 시각적으로 강조 (`.decisions` 클래스)
- [ ] **결정 사항 3~6개**, 각 결정에 **결정문 형식** — "X SKU OK 결정 / 발주 수량 N / LOCK 일자"
- [ ] NG 결정 시 **구체적 사유** 명시 — 원가 초과 N% / 핏 미흡 / 컬러 발색 미흡 / 크로스 코디 부적합
- [ ] 액션 아이템 표 4~6행 — 액션 + 오너(아바타) + 기한 + 상태 모두 채워짐
- [ ] 상태 칩 **4종 모두 등장** — `미진행` / `진행 중` / `블락` / `완료` (회색 / 액센트 / 빨강 / 녹색)
- [ ] 미결 이슈 + 다음 미팅 2컬럼 그리드 채워짐
- [ ] 다음 미팅 정보에 일시 + 장소 + 아젠다 + **작성자(로테이션)** 모두 명시
- [ ] 모든 색상은 `:root` 토큰에서 옴 — 임의 hex 금지

## P1 — 강력 권장

- [ ] 본문 폰트 `Pretendard Variable`, 디스플레이는 `--font-display-report` (콜라보 미팅은 `--font-display-romance` 옵션)
- [ ] SKU 코드 표기 표준 — `WW-27SS-OUT-014` 형식 (브랜드-시즌-카테고리-연번)
- [ ] 산업용어 유지 — SKU / BTA / OEM / LOT / MOQ / QR / SPOT / 컬러웨이 / 캐리오버 / 사입가율 / 정상판매율
- [ ] 결정문에 **발주 수량 + LOCK 일자 + 책임 부서**가 모두 등장
- [ ] 액션 아이템 기한 표기 `27/MM/DD (요일)` 형식
- [ ] 아바타에 직책 또는 이니셜 (대표·PK·MH·JW·SY 등) — 풀네임 직접 표기는 옆에
- [ ] 회의록 푸터에 **저장 위치(노션 / 카카오워크 위키 / 슬랙)** 명시

## P2 — 다듬기

- [ ] 시즌 코드 표기 일관성 (`27SS`, `26FW`)
- [ ] 액션 아이템 표 상태 칩 색상이 직관적 (블락 = 빨강, 완료 = 녹색)
- [ ] 모바일 720px 폭에서 `.grid` 1열 폴백, 패딩 줄어듦
- [ ] 아젠다의 오픈 토픽(미완료)은 체크박스 빈 상태로 표시
- [ ] 결정 사항 패널의 `<li>` 마커가 액센트 컬러
- [ ] 24시간 내 슬랙·노션 공유 액션이 액션 아이템에 1건 포함 (완료 상태 표기)

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 참석자 직책 없이 이름만 → 한국 패션기업 직책(실장 / 디자이너 / MD) 명시
- [ ] 결정 사항이 보고서 형식("X에 대해 논의함") → **결정문 형식**("X SKU OK 결정 / 발주 N / LOCK 일자")으로 재작성
- [ ] NG 결정에 사유 없음 → 원가 / 핏 / 컬러 / 코디 사유 중 1개 이상 명시
- [ ] 액션 아이템 표에 오너 없음 → 모든 액션에 오너 + 기한 명시
- [ ] 상태 칩 1~2종만 사용 → 4종 모두 등장 (미진행 / 진행 중 / 블락 / 완료)
- [ ] 다음 미팅 정보 비어있음 → 일시 + 장소 + 아젠다 + 작성자 명시

## K-패션 특화 검수 (선택)

- [ ] 1차/2차 품평회 시점이 시즌 사이클 정합 — 1차 시즌 4개월 전 (1월), 2차 시즌 3개월 전 (2월)
- [ ] 발주 회의 결정에 OEM 공장 명시 — 합천 / 진주 / 안양 / 의정부 등
- [ ] 콜라보 미팅의 라이선스 비용 표기 % 또는 정액
- [ ] 시즌 킥오프 미팅의 시즌 컨셉이 K-패션 자연 — "WACKY GARDEN", "BLOOM 27SS", "마뗑킴 NIGHT MARKET" 등
- [ ] 회의록 작성자 직책 — MD / 디자인실 어시스턴트 / 마케팅 실장 (한국 패션기업 회의록 표준 작성자)
- [ ] 24시간 내 공유 액션이 완료 상태로 액션 아이템에 1건 등장 (한국 패션기업 표준 실무)
