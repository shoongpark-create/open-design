# K-패션 5차원 비평 자체 검수 체크리스트

비평 보고서 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 5개 차원이 **모두** 점수+근거+태그 카드로 작성됨 (부분 보고서 금지 — 3차원만 평가 NO)
- [ ] 각 차원 점수 옆에 **30-80단어 근거**가 작성됨. 근거에 룩 번호·SKU 코드·페이지·클래스명 인용 (`룩 09`, `<code>CW01 OAT</code>`, `P14`)
- [ ] 레이더 차트(인라인 SVG) 5축이 모두 표시. 폴리곤이 0~10 스케일로 점수 좌표에 정확히 닿음
- [ ] 점수표(score-row) 5행이 차원 카드와 정확히 일치 (점수표 7점인데 카드에 8점 같은 불일치 금지)
- [ ] 종합 점수(`hd-verdict`)가 5차원 평균 또는 가중 평균과 ±0.4 이내 일치
- [ ] 액션 리스트 3개 카드(Keep / Fix / Quick wins) 모두 채워짐. 최소 3건씩
- [ ] 외부 이미지 URL 없음 (CDN, /tmp, base64 모두 금지). 인라인 SVG만 사용
- [ ] **점수 인플레 금지** — 모든 점수가 7+면 비평이 비판적이지 않음. 최소 1개 차원 0-6 권장

## P1 — 강력 권장

- [ ] 근거가 **명사구 종결** (`톤 일관성 부족`, `재촬영 검토`, `MD 검토 필요`). `~이다`/`~한다` 회피
- [ ] 차원 이름이 **한국어 + 영문 혼용** (`브랜드 톤 정합성 · Brand-tone Consistency`)
- [ ] 점수 밴드 라벨이 표시됨 (`깨짐 0-4`, `기능적 5-6`, `강함 7-8`, `탁월 9-10`)
- [ ] Keep / Fix / Quick win 태그가 5차원 카드 각각에 1~2건씩 배치
- [ ] Quick win은 **5-15분 작업**, **시그널 대 노이즈 비율 높음** 항목 (전체 재촬영 같은 무거운 항목 금지)
- [ ] 시즌 차별성 점수가 의도적으로 낮을 수 있음 (캐리오버 위주 시즌 5/10 OK). 적절한 보수성을 처벌 금지
- [ ] 카피·SKU 인용에 mono 폰트 (`<code>` 또는 `font-family: var(--mono)`)
- [ ] 검토자 표기에 직무 + 이름 (`디자인실장 강윤` 또는 `OD critique skill`)

## P2 — 다듬기

- [ ] 시즌 코드 표기 일관 (`27SS`, `27FW`)
- [ ] 헤더 일자가 ISO-like 한국 포맷 (`2026.05.14`)
- [ ] 푸터에 스킬 버전 + 5차원 라벨 (`OD · Critique skill · v0.2 · K-패션 판`)
- [ ] 색상 토큰: `--good`(Keep) / `--warn`(Fix) / `--info`(Quick win) 일관 적용
- [ ] 모바일 900px 폭 이하에서 `dim-grid`·`lists-grid`·`review-grid`가 1열로 스택
- [ ] 인쇄 시 한 페이지에 헤더+레이더+차원 카드가 들어가도록 `@media print` 권장

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 비평이 *느낌* 수준에 머문 것입니다 — 반드시 보강.

- [ ] 근거에 "느낌이 어색함" / "조금 별로" / "분위기가 안 맞음" 같은 무근거 표현 → 룩 번호·SKU·페이지 인용으로 교체
- [ ] 모든 5차원이 7+ → 최소 1개 차원의 약점 발견 (없으면 비평이 아니라 추천)
- [ ] Keep / Fix / Quick win이 같은 항목 반복 → 각 카드는 독립 항목
- [ ] 같은 턴에서 본인 산출물 비평 (사용자가 명시 요청하지 않은 경우) → 금지
- [ ] 한 문장으로 "전반적으로 좋습니다" 종합 평가 → 차원별 점수의 가중 평균이 어떻게 도출되는지 명시

## 레이더 좌표 계산 (참고)

5축 펜타곤. 중심 (150, 150), 반지름 110 = 10/10. 각 축 점수 N → 좌표:

```
브랜드 톤 (top, -90°)     :  150 + 0,        150 - 11*N
시각 위계 (TR, -18°)      :  150 + 10.46*N,  150 - 3.40*N
디테일 (BR, 54°)          :  150 + 8.90*N,   150 + 6.47*N
기능성 (BL, 126°)         :  150 - 6.47*N,   150 + 8.90*N (보정 필요시 데모 코드 참조)
시즌 차별성 (TL, -162°)   :  150 - 10.46*N,  150 - 3.40*N
```

예시 산출물 `example.html`의 SVG가 이 계산을 반영하므로 좌표는 그대로 복사 후 점수값만 교체 권장.
