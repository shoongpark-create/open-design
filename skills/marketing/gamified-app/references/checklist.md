# K-패션 멤버십 챌린지 앱 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **3개 폰 = 3개 다른 목적.** 폰 1 = 표지 / 폰 2 = 대시보드 / 폰 3 = 디테일. 같은 화면 3번 반복 금지.
- [ ] **6개 챌린지 타일 = 6개 다른 파스텔 컬러.** `--tile-1` ~ `--tile-6` 6변수 사용. 한 색만 반복 금지.
- [ ] **게임 RPG 클리셰 0개.** `퀘스트`(단독), `용사`, `전사`, `Adventure`, `Master`, `Bronze 1` 단독 등장 금지. `챌린지` / `미션` / `등급 업그레이드` / `포인트` / `마일리지`로 치환.
- [ ] **`XP` 단독 표기 없음.** 모두 `pt` 또는 `P` (point/포인트)로 치환. 예: `+90 pt`, `1,648 pt`, `BONUS +200pt`.
- [ ] **등급명이 패션 멤버십 톤.** `SILVER / GOLD / PLATINUM / VVIP` 또는 `WELCOME / 단골 / VIP`. 게임 톤(`Bronze 1`, `Master`) 금지.
- [ ] **포인트 숫자는 mono + tnum.** 등급 진척, 적립 포인트, 누적 금액 모두 `var(--font-mono)` + `font-variant-numeric: tabular-nums`.
- [ ] **하트·불꽃 이모지 절대 금지.** 데이팅 클리셰. 챌린지 글리프는 1글자 영문(O/L/I/S/T/W) 또는 SVG monoline. ❤️🔥💕 모두 사용 금지.
- [ ] **외부 이미지 URL 없음.** 모든 비주얼 CSS 그라데이션 + 인라인 SVG. CDN 이미지 금지.
- [ ] **3개 폰 모두 노치 + 상태 바 + 탭바 보유.** 시드의 `.phone::before`(노치), `.status`(상태 바), `.tabbar`(탭바) 마크업 삭제 금지.
- [ ] **탭바 5개 탭 표준 (홈 · 카테고리 · ⊕ · 챌린지 · 마이).** 폰 2의 활성 탭 = 홈, 폰 3의 활성 탭 = 챌린지.
- [ ] **액센트 컬러 사용 ≤ 4회 per 폰.** 폰 1: eyebrow dot + 헤드라인 핵심 단어 + next-peek swatch (3회). 폰 2: 레벨 진척 바 + 활성 탭 + sub pill (3회). 폰 3: 우상단 스탬프 + 완료 체크 + 활성 탭 (3회). 5회 이상 금지.
- [ ] **`data-od-id` 속성이 stage-bar · phones · phone-cover/home/detail · 주요 섹션에 있음** (OpenDesign 환경). 그 외는 `id` 속성 대체 가능.

## P1 — 강력 권장

- [ ] **친근 + 어른 톤.** 회원 호칭 `@minji 님`, `회원님` 사용. 어린이 톤(`귀여운 챌린지~`, `재밌어요!`) 금지. 동시에 너무 차갑지 않게.
- [ ] **챌린지 이름이 짧은 명사구.** `오늘의 룩 인증`, `룩북 저장`, `친구 초대`, `매장 방문`, `인스타 태그`, `위시리스트 추가`. 동사형 길게(`매일매일 오늘의 룩을 인증해보세요!`) 금지.
- [ ] **챌린지 설명이 한 줄.** `27SS OOTD 인증 #wackywilly_27ss · 인스타 공개 계정`. 2줄 이상 금지.
- [ ] **회원 핸들이 `@핸들` 형식.** `@minji`, `@minji_27ss` 같은 영문 핸들 권장. 한글 닉네임은 부자연스러움.
- [ ] **레벨 리본 진척 바 채움 비율이 합리적.** `1,648 / 2,480 pt`라면 약 66% 채움 — 시드 기본값. 100% 또는 0% 채움 금지.
- [ ] **6개 챌린지의 적립 포인트 합리적인 범위.** 작은 액션(위시 추가) = `+30 pt`, 큰 액션(매장 방문) = `+70~90 pt`. 가장 큰 값과 작은 값의 차이가 3배 이내 권장.
- [ ] **상태 바 시간은 `9:41`** (Apple 표준).
- [ ] **카피에 K-패션 영문 산업용어 자연 혼용** — `LOOKBOOK`, `DROP`, `OOTD`, `MEMBERS ONLY`, `MEMBERSHIP`, `BONUS`, `STREAK`.
- [ ] **시즌 코드 표기 정확.** `27SS` / `27FW`, 공백 없이.

## P2 — 다듬기

- [ ] **CTA가 행동 동사.** `챌린지 시작`, `OOTD 인증하기`, `친구 초대`, `포인트 사용`, `룩북 다운로드`. `더보기`/`자세히` 금지.
- [ ] **폰 1 헤드라인 핵심 단어 1개에만 `.accent` 적용.** 2개 이상 단어에 `.accent` 사용 금지 — 강조가 분산됨.
- [ ] **폰 1 `tip` 라인이 mono + 점선 보더.** 시드 기본값. 본문 폰트로 바꾸지 마세요.
- [ ] **폰 3 히어로 그라데이션이 시즌·캠페인 톤 일치.** 봄 = 코랄·오렌지 톤, 여름 = 블루·민트, 가을 = 머스타드·번트 오렌지, 겨울 = 차콜·아이보리.
- [ ] **푸시 알림 카피가 친근한 호칭** (`@minji 님`, `오늘의 룩 어땠어요?`).

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 K-패션 멤버십 톤이 아닙니다 — 반드시 수정.

- [ ] 같은 화면 2개 이상 반복 → 폰 1·2·3 각각 다른 목적
- [ ] 6개 챌린지 타일이 같은 색 2번 이상 등장 → 6개 모두 다른 파스텔
- [ ] `퀘스트`, `용사`, `XP`(단독) 등장 → K-패션 멤버십 용어로 치환
- [ ] 등급명에 `Master`, `Diamond`, `Bronze 1` → SILVER/GOLD/PLATINUM/VVIP로 치환
- [ ] 하트·불꽃 이모지 사용 → 1글자 영문 글리프 또는 SVG monoline
- [ ] 회원명이 `User1234` 같은 placeholder → 실제 핸들(`@minji`, `@minji_27ss`)
- [ ] 데이팅 톤(`매칭 성공!`, `당신의 짝꿍은…`) → 패션 큐레이션 톤(`이번 시즌 추천 룩`)
- [ ] 적립 포인트 단위 불일치 (`+90`, `+90P`, `+90 포인트` 혼용) → 한 산출물에 한 표기로 통일

## K-패션 특화 검수 (선택)

- [ ] 카피·라벨에 K-패션 영문 산업용어 (`OOTD`, `LOOKBOOK`, `DROP`, `STREAK`, `BONUS`, `MEMBERS ONLY`, `MEMBERSHIP`)
- [ ] 챌린지가 한국 채널 연계 — 카카오톡 친구 초대, 인스타 태그, 매장 QR 스캔, 무신사 단독, 카페24 자사몰
- [ ] 시즌 키비주얼 컬러가 액센트와 일치 (액센트 = 시즌 키 컬러)
- [ ] 브랜드 톤 일치 (와키윌리 = 위트, 마뗑킴 = 미니멀, 마르디 = 로맨틱)
- [ ] 채널 R&R 정합성 — 챌린지 인증 = 인스타, 알림 = 카카오톡, 적립 = 자사몰 마이페이지
