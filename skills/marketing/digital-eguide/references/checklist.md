# K-패션 디지털 e-가이드 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 두 페이지 카드(`.page.left.cover` + `.page.right.spread`)가 모두 존재. 단일 페이지 가이드 금지
- [ ] 표지에 **이탤릭 액센트 단어 정확히 1회** (`Spring *Layering* 101`처럼 `<span class="ital">` 1회). 2회 이상 사용 금지
- [ ] 스프레드 서브타이틀에 **이탤릭 액센트 1회** (`only *quieter*`처럼 `<span class="accent">` 1회)
- [ ] 표지 통계 3-셀이 모두 채워짐. 빈 셀 금지 (`04 CHAPTERS / 12 LOOKS / 3 COLORWAYS` 같은 K-패션 등록)
- [ ] TOC가 4~6개 챕터로 작성. 챕터 번호 + 한국어 부제 + 페이지 번호 형식
- [ ] 스프레드 본문이 **2단** (`.columns`) — 좌 = 오프닝 단락, 우 = 4단계 리스트 (`.steps`)
- [ ] 4단계 리스트가 **영문 + 한국어 혼용** (`<b>Drop the shoulder.</b> 어깨를 떨어뜨리세요.` 형식)
- [ ] 풀쿼트가 디자이너/스타일리스트 어트리뷰션 포함 (`— 매트 김 · CHAPTER 02 · LAYER`)
- [ ] EXERCISE 콜아웃 1개 — 1문장 시적 명령 (`옷장에서 가장 가벼운 한 겹을 꺼내, 오늘 가장 *조용한* 룩으로 입어 보세요.`)
- [ ] 외부 이미지 URL 없음 (CDN 폰트만 허용). 모든 도형은 CSS 또는 인라인 SVG
- [ ] mono 폰트가 **라벨·통계·TOC 번호·페이지 번호에만** 사용. 본문에 mono 금지

## P1 — 강력 권장

- [ ] 두 페이지 카드가 살짝 반대 방향으로 기울어 책상 위 책 메타포 (`.left { rotate: -0.6deg }` / `.right { rotate: 0.6deg }`)
- [ ] 표지 디스플레이 제목이 60~92px의 큰 사이즈로 페이지를 지배
- [ ] 스프레드 서브타이틀이 44px 전후로 스프레드를 지배
- [ ] 풀쿼트가 우측 오버레이로 살짝 회전 (`transform: rotate(2.4deg)`)
- [ ] 카피 톤이 **포엣코어** — 직설 스타일링 팁(`늘어나는 코튼 셔츠`) 금지. 감각·계절감 표현(`정원의 잔향이 머무는`) 우선
- [ ] CHAPTER 라벨이 영문 대문자 + mono (`CHAPTER 02 · LAYER`). 한국어 음차(`챕터 02`) 금지
- [ ] 본문 좌측 컬럼 첫 글자에 드롭캡 (`.columns p:first-letter`)
- [ ] EXERCISE 라벨이 액센트 보더 + 액센트 컬러 (`border: 1px solid var(--accent)`)
- [ ] 표지 시그니처 스티커가 둥근 모티프 또는 시즌 모티프 (꽃·체리·캐릭터)
- [ ] 페이지 번호가 `01 / 48` 같은 mono 분수 형식

## P2 — 다듬기

- [ ] 시즌 코드 표기 일관 (`27SS`, `27FW`)
- [ ] 저자 바이라인이 영문 워드마크 + 한국어 + 일자 (`— BY MATIN KIM STYLING DESK · 매트 김 · 10 / 04 / 2027`)
- [ ] 챕터 번호가 zero-padded (`01`, `02`, `03`)
- [ ] 모바일 1180px 폭 이하에서 두 페이지가 세로로 스택, 풀쿼트가 카드 안으로 들어옴
- [ ] 액센트 컬러 사용이 2~3 위치(풀쿼트 + EXERCISE 보더 + 드롭캡)로 절제
- [ ] 표지 통계 라벨이 영문 대문자 + 한국어 부제 (`CHAPTERS · 봄의 네 가지 결`)

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 e-가이드가 광고 톤에 가까운 것입니다 — 반드시 보강.

- [ ] 카피 톤이 SaaS/광고 톤 (`지금 다운로드`, `무료 가이드`, `한정 혜택`) → 절제된 에디토리얼 톤으로 교체
- [ ] 디스플레이 제목에 이탤릭 액센트가 0회 또는 3회+ → 정확히 1회
- [ ] 4단계 리스트가 1단계만 영문 + 나머지 한국어 → 4개 모두 영문 + 한국어 혼용
- [ ] 풀쿼트가 어트리뷰션 없음 → 디자이너/스타일리스트 + 챕터명 인용
- [ ] EXERCISE가 명령이 아니라 정보 (`오늘은 봄날입니다`) → 시적 명령(`옷장에서 ~을 꺼내, ~로 입어 보세요`)

## K-패션 특화 검수 (선택)

- [ ] 라벨에 영문 산업용어 (`STYLING GUIDE`, `LAYER`, `FIT`, `COLORWAY`, `KEY ITEM`, `CHAPTER`, `EXERCISE`)
- [ ] 채널 매칭 — PDF 다운로드 / 카카오톡 친구톡 / 자사몰 회원 라운지 / 무신사·29CM 큐레이션 / 인스타그램 캐러셀 (8~10장 재크롭 가능한 비율)
- [ ] 시즌 사이클 정합 — 시즌 시작 1개월 전(스타일링 가이드), 시즌 중반(데일리 핏), VIP 가입 직후(VIP 가이드)
- [ ] 부서 R&R — 카피·기획은 마케팅실(에디터), 시각·일러스트는 디자인실(그래픽팀), 스타일링 노하우는 디자이너/스타일리스트 인용
