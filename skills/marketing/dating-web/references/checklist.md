# K-패션 VIP 라운지 / 스타일 매칭 대시보드 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **데이팅 클리셰 0개.** 하트(❤️💕💘), 불꽃(🔥), `spark`, `match`(데이트 의미), `Find your perfect match`, `sparkling` 절대 사용 금지. "스타일 매칭"은 패션 큐레이션 용어로 OK (단, 데이팅 톤 아닌 큐레이션 톤으로).
- [ ] **매거진 에디토리얼 톤.** 신문 일요판 컬럼처럼 차분하고 관조적. 호들갑·과장(`대단해요!`, `놀라워요!`, 느낌표 남발) 금지.
- [ ] **액센트 컬러 사용 3~4회.** 일반적 분포: 차트 마지막 2일 막대 액센트 + KPI value.accent 1개 + 네비 active 1개 + 트렌드 강조 1개. 4회 이상이면 매거진 톤이 깨집니다.
- [ ] **9개 KPI 모두 구체적 수치.** lorem ipsum 또는 `XXX`, `활동 양호` 같은 모호한 노트 금지. 구체적 수치(`최근 30일 +14 룩`, `같은 컬렉션에서 8회`).
- [ ] **차트 막대 ~30개 (일별), 마지막 2일 액센트.** SVG 인라인. 외부 차트 라이브러리 금지. 막대 개수가 30개와 ±2 차이면 OK, 그 외는 패턴 차트 의미가 맞지 않음.
- [ ] **숫자에 `font-variant-numeric: tabular-nums`.** 시드의 `.stat .value`와 `.num` 클래스가 적용. 숫자 정렬이 깨지면 안 됨.
- [ ] **3폰트 조합 — 세리프 디스플레이 + mono + (세리프 본문 또는 sans).** KPI 큰 숫자 = 세리프 디스플레이, 라벨/축 = mono, 본문 노트 = 세리프 본문(이탤릭 권장). 한 폰트로 통일 금지.
- [ ] **외부 이미지 URL 없음.** 모든 차트는 SVG 인라인. CDN 이미지·base64 금지.
- [ ] **티커 슬로건이 짧은 절.** 예: `당신의 취향이 만든 라운지 · 매주 월요일 큐레이션 리뉴얼`. 데이팅 클리셰 없음.
- [ ] **`data-od-id` 속성이 ticker · rail · main · kpis · bars · trend · nav 그룹에 있음** (OpenDesign 환경). 그 외는 `id` 속성 대체 가능.
- [ ] **레일 active 항목 1개만.** `<li class="active">` 두 개 이상 금지.

## P1 — 강력 권장

- [ ] **회원 핸들이 `@핸들` 형식.** `@minji`, `@minji_27ss` 같은 영문 핸들 권장. 한글 닉네임은 부자연스러움.
- [ ] **등급명 영문 통일.** `SILVER / GOLD / PLATINUM / VVIP`. 한국어(`골드`, `플래티넘`) 또는 mixed(`Gold 등급`) 회피.
- [ ] **누적 금액 표기 ₩XXX,XXX 또는 ₩X.XM.** `$XXX` 표기 금지 (글로벌 자사몰 아닌 한). 큰 금액은 `₩4.6M` 같은 축약.
- [ ] **KPI 노트가 이탤릭 한 줄.** 시드 기본값. 한 줄에 1개 통계 + 1개 해석. 예: `이번 주 +12 · 건강한 증가.`, `코호트 중위 +18% · 강한 일치.`.
- [ ] **good/bad 컬러 적절히 사용.** `Match rate 62%` → good (녹색), `Discounted only 4` → bad (붉은색). 임의 사용 금지 — 비즈니스 의미와 일치.
- [ ] **티커 mono uppercase 영문 + 한국어 혼용.** 예: `당신의 취향이 만든 라운지 · REVIEWED WEEKLY · NEXT TIER VVIP · ₩2,400,000 남음`.
- [ ] **차트 캡션 mono uppercase 영문 + 한국어.** `↑ TRENDING UP · +14 MATCHED LOOKS THIS MONTH · TWO FROM 27SS DROP`.
- [ ] **트렌드 해석 한국어 본문 1~2문장 + 영문 mono 캡션.** 시드 기본값 참조.
- [ ] **네비 라벨 한국어/영문 혼용.** 그룹 제목은 영문(`Today` / `You` / `Archive`), 항목은 한국어(`오늘의 추천`, `위시리스트`).

## P2 — 다듬기

- [ ] **레일 워드마크가 세리프 이탤릭 + `.dot` 액센트.** 예: `matin kim.` (마지막 닷이 액센트 컬러).
- [ ] **상태 라인이 `● 온라인 · 마지막 방문 11분 전 · matin kim lounge v.2.7.1`.** 시드 기본값.
- [ ] **모바일 1100w 이하에서 레일이 위로 스택.** 시드 미디어 쿼리에 이미 정의.
- [ ] **KPI 큰 숫자 가운데 1~2개에 액센트 컬러 (`value.accent`)** — 가장 강조하고 싶은 수치 1개에만.
- [ ] **3폰트가 위계대로** — 큰 숫자 = 디스플레이 세리프, 본문 노트 = 본문 세리프 이탤릭, 라벨/티커 = mono.
- [ ] **푸터 또는 하단에 라운지 버전/이용약관 링크** (선택).

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 K-패션 매거진 라운지 톤이 아닙니다 — 반드시 수정.

- [ ] 데이팅 톤 어휘 사용 (`spark`, `flame`, `match made in heaven`) → 큐레이션 톤으로 교체
- [ ] 9개 KPI 중 1개라도 mock value (`XXX`, `123`, `lorem`) → 구체적 수치
- [ ] 액센트 5회 이상 사용 → 3~4회로 줄이고 가장 강조하고 싶은 곳만 남김
- [ ] 차트가 외부 이미지/iframe → SVG 인라인으로 교체
- [ ] 노트가 모호 (`활동 양호`, `좋아요`) → 구체적 수치/해석
- [ ] 본문 카피가 호들갑 (`대단해요!`, `놀라워요!`, 느낌표 3개 이상) → 관조적 매거진 톤
- [ ] 회원명이 `User1234`, `회원1` → 실제 핸들(`@minji_27ss`)
- [ ] 모든 텍스트가 한 폰트(예: Pretendard만 사용) → 3폰트 조합으로 변경

## K-패션 특화 검수 (선택)

- [ ] 카피·라벨에 K-패션 영문 산업용어 (`LOOKBOOK`, `DROP`, `WISHLIST`, `MATCHED LOOKS`, `MEMBERS ONLY`, `MEMBERSHIP`, `VIP/VVIP`)
- [ ] 가격·포인트 한국 표준 표기 (`₩214,000`, `₩4.6M`, `+50P`)
- [ ] 네비 항목이 K-패션 마이페이지 표준 (`위시리스트`, `오늘의 추천`, `포인트 내역`, `과거 룩북`, `만료된 쿠폰`)
- [ ] 시즌 코드 정합 (`27SS`, `27FW` — 공백 없이)
- [ ] 채널 R&R 표시 — 1:1 상담 = 채널톡, 알림 = 카카오톡, 매장 초대 = 매장 POS
- [ ] 매거진 인용 영문 워드마크 (`VOGUE KOREA`, `W KOREA` 등 — 사용 시 직역 금지)
