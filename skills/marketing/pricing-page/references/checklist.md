# K-패션 멤버십 가격 페이지 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 5개 섹션 모두 존재 — 헤더 / 등급 카드 / 혜택 비교표 / FAQ / 푸터 CTA
- [ ] 등급명은 **영문 유지 표준** — `BASIC` / `SILVER` / `GOLD` / `PLATINUM` / `VIP` (또는 브랜드 고유 명칭). `실버`·`골드` 음차는 본문 보조 설명에서만
- [ ] 추천 등급 **정확히 1개** — `featured` 클래스 + `MOST POPULAR` 또는 `RECOMMENDED` 또는 `INVITATION ONLY` 배지. 2개 이상 강조 금지
- [ ] **K-패션 등록 카피** — `구매액 X% 적립`, `시즌 사전예약 X시간 우선`, `시즌 룩북 우편 발송`, `매장 시즌 행사 초대`. SaaS 어휘(`Premium Feature`, `Advanced Support`, `Pro plan`) 금지
- [ ] **가격·금액 표기** — `₩128,000` 또는 `128,000원` 한 형식으로 통일. `$X / month`, `€X` 같은 SaaS·해외 표기 금지
- [ ] 누적 구매 조건 명시 — `누적 ₩300,000 이상`, `12개월 누적 ₩100만 이상`, `초대제` 같은 K-패션 멤버십 등록
- [ ] 외부 이미지 URL 없음 (CDN 폰트만 허용). 등급 카드 데코는 CSS로 처리
- [ ] FAQ는 한국 고객 실제 질문 — `등급은 언제 갱신되나요?`, `등급이 떨어질 수 있나요?`, `시즌 사전예약은 며칠 전부터?`, `VIP는 어떻게 초대되나요?`

## P1 — 강력 권장

- [ ] 등급 카드에 **등급 컬러 토큰** 표시 (`.tier-color` 4px 라인 — BASIC 회색, SILVER 메탈릭 그레이, GOLD 따뜻한 골드, PLATINUM 딥 차콜, VIP 액센트)
- [ ] **혜택을 2~3개 논리 그룹으로 묶기** — `적립·할인` / `배송·CS` / `시즌 혜택`. 그룹 헤더(`tr.group-head`)로 분리
- [ ] **적립률 단계** K-패션 표준 — 0.5% → 1% → 2% → 3% → 5%
- [ ] **시즌 사전예약 우선권** 단계 — 12시간 → 24시간 → 48시간 → 1주
- [ ] **CTA 카피가 K-패션 톤** — `BASIC으로 시작`, `GOLD 혜택 보기`, `PLATINUM 안내 신청`, `VIP 안내 신청`. SaaS 톤(`지금 가입`, `시작하기`, `Free trial`) 금지
- [ ] **헤더 데크가 한국 패션 톤** — `오래 머무를수록, 더 가까이.`, `다음 시즌, 가장 먼저.`, `매트 김 회원이 되어주세요.`
- [ ] **헤더 eyebrow** = `[브랜드] · MEMBERS` 형식 (mono + uppercase + tracking)
- [ ] FAQ가 4~6개 — JS 없이 `<details><summary>` 사용
- [ ] **모바일 600px 폭** 이하에서 등급 카드 1열, 비교표 가독성 유지(가로 스크롤 또는 폰트 축소)

## P2 — 다듬기

- [ ] **가격 숫자에 디스플레이 세리프** (`.price`) — 28~32px, `font-family: var(--serif-display)`
- [ ] **누적 조건 라벨에 mono** (`.price small`) — `누적 ₩300,000 ~ ₩999,999`
- [ ] **비교표 헤더 셀** — `font-family: var(--mono)` + uppercase + tracking
- [ ] **시즌 코드 표기** 일관 (`27SS`, `27FW`)
- [ ] **푸터 CTA 액센트 밴드** — 절제 사용 (전체 페이지에서 액센트 컬러 사용 ≤ 3회)
- [ ] **details 화살표 글리프** — `+` ↔ `−` 또는 `▸` ↔ `▾` 일관
- [ ] **closing 섹션 라운드 보더** + 액센트 배경
- [ ] **티어 컬러 라인 우선순위** — PLATINUM이 가장 어두운(딥 차콜) = 가장 높은 등급 신호

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 페이지가 SaaS 풍에 빠진 것입니다 — 반드시 K-패션 톤으로 보강.

- [ ] 가격이 `$29 / month` 또는 `€39 / quarter` → 원화 표기로 교체
- [ ] 혜택명이 `Premium Feature 1`, `Advanced Support`, `Pro Tier` → `시즌 사전예약 24시간 우선` 같은 K-패션 등록
- [ ] CTA가 `Start Free Trial`, `Subscribe Now`, `Upgrade Now` → `사전예약 신청`, `GOLD 혜택 보기`, `VIP 안내 신청`
- [ ] 추천 등급이 2개 이상 → 1개만 강조
- [ ] 등급명이 `Tier 1 / Tier 2 / Tier 3` → BASIC/SILVER/GOLD/PLATINUM/VIP 등 K-패션 등록명
- [ ] 모든 등급에 동일 적립률 → 등급별 차등 (0.5 → 1 → 2 → 3 → 5%)
- [ ] FAQ가 일반 SaaS 질문 (`Can I cancel anytime?`) → 한국 패션 고객 질문 (`등급은 언제 갱신되나요?`)

## K-패션 특화 검수 (선택)

- [ ] **이중 멤버십 명시** — 무신사 입점 브랜드는 무신사 멤버스와 자사몰 멤버스가 별도 운영됨. 자사몰 멤버십 안내 페이지에서 무신사 멤버스와의 차이 언급 권장
- [ ] **카카오톡 알림톡 명시** — 시즌 사전예약·등급 업그레이드 알림은 카카오톡 알림톡으로 발송
- [ ] **매장 채널** — 직영 매장 / 팝업 매장 POS에서 등급 확인 가능 여부 명시
- [ ] **VIP 분리 운영** — PLATINUM과 VIP를 분리하는 경우, VIP는 초청제 + 디자이너 미팅·패션쇼 초청 같은 비매개 혜택 강조
- [ ] **누적 구매액 기간** — `최근 12개월 누적` vs `연 누적` 토글 또는 한 가지 명시
- [ ] **부서 R&R** — 마케팅실 CRM/멤버십 매니저(정책·카피) + 이커머스팀(페이지 제작·등급 자동 부여 로직) + 디자인실 그래픽팀(등급 배지·카드 컬러) 협업
