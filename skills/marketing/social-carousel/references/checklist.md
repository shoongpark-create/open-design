# K-패션 인스타그램 캐러셀 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **카드 정확히 3장.** 2장·4장 금지. 3-카드 캐러셀의 표준
- [ ] **3개 헤드라인을 연속해서 읽으면 한 문장**으로 자연스럽게 흐름 (`Quiet. · Steady. · Now.` 또는 `시작. · 이어서. · 오늘도.`)
- [ ] **마지막 카드에 CTA 또는 시즌 코드 / 발매 정보** (`Shop Now.`, `Pre-order.`, `룩북 보기.`, `03.14.` 등)
- [ ] 각 카드 = **1080×1080 정사각형** (`aspect-ratio: 1 / 1`). 인스타그램 1:1 표준
- [ ] 카드 3장의 **도미넌트 컬러가 분명히 다름** (같은 색조 2장 금지). 카드별 `data-index` 속성으로 컬러 분기
- [ ] **외부 이미지 URL 없음** (CDN, /tmp, base64 모두 금지) — 배경은 레이어드 그라데이션 only
- [ ] 각 카드에 다음 요소 모두 존재:
  - 좌상단 `chip` (브랜드 워드마크 + 액센트 도트, backdrop-blur)
  - `chip` 아래 `idx` (`27SS · 01 / 03` 형식 mono 인덱스)
  - 좌하단 `lockup` (헤드라인, 디스플레이 폰트)
  - 우하단 `loop` (`1× LOOP` mono 스탬프, 얇은 보더)
  - 좌하단 헤드라인 위 `caption` (mono 영문 대문자 + 한국어 보조 1줄)
- [ ] mono 폰트는 `chip 인덱스` / `LOOP 스탬프` / `caption`에만 사용. 헤드라인은 디스플레이 폰트 유지
- [ ] **1180px 이하 뷰포트에서 카드가 세로 스택**, 헤드라인 폰트가 한 단계 축소
- [ ] 카피 톤이 **포엣코어** — 직설 설명(`늘어나는 코튼`)이 아니라 감각·계절감·시즌 컨셉 (`Quiet. · 정제된 하루.`)

## P1 — 강력 권장

- [ ] 다크 스테이지 배경 (`--stage: #0a0a0a`) + 카드가 페이지 위에 떠 있는 메타포 (드롭 섀도)
- [ ] 카드 둥근 모서리 12~14px + 1px 보더 + 드롭 섀도. 시드 기본값 유지
- [ ] 액센트 단어 1개에 `accent-word` 클래스 (이탤릭 + 액센트 컬러) — 카드 2와 3에 주로
- [ ] 스테이지 헤더 좌측 = `Three posts. One series.` 톤 + 우측 = `SERIES · 01 → 03` 뱃지
- [ ] 캡션 = 영문 대문자 + 한국어 보조 (`LOOK 01 · CAMPAIGN STILL` + `정제된 하루, 그 자체.`)
- [ ] 카드별 `data-index="1"`, `data-index="2"`, `data-index="3"` 정확히 매핑 (CSS 컬러 분기)
- [ ] 디스플레이 폰트 1개만 `--font-display`에 바인딩 (romance / play / street / report 중 1개)

## P2 — 다듬기

- [ ] 카드 안 추상 실루엣 (`.silhouette` 클래스)이 옵션으로 들어있고 너무 과하지 않음
- [ ] 카드 3장 그라데이션 방향이 다름 (165deg / 155deg / 195deg) — 시각적 단조로움 회피
- [ ] 카드 chip 안 도트가 시즌 키 액센트 컬러
- [ ] 인덱스 표기 일관 (`27SS · 01 / 03`, `27SS · CAPSULE · 02 / 03`)
- [ ] 스테이지 풋터에 채널·시즌·DROP 메타 (`INSTAGRAM · LOOPS · 27SS · DROP 02 · 1080×1080`)

## 시리즈 헤드라인 검수

3개 카드를 연속해서 읽었을 때 자연스러운지 확인:

- [ ] **카드 1**: 시작·정체성 (`Quiet.`, `Wacky.`, `Mardi.`)
- [ ] **카드 2**: 키 아이템·시즌 시그니처 (`Steady.`, `Willy.`, `en Fleur.`)
- [ ] **카드 3**: CTA·시즌 코드·발매 일자 (`Now.`, `오늘도.`, `03.14.`, `Lookbook.`)

### 올바른 사례

- `Quiet.` → `Steady.` → `Now.` (마뗑킴 톤)
- `Wacky.` → `Willy.` → `오늘도.` (와키윌리 톤)
- `시작.` → `이어서.` → `오늘도.` (한국어 시리즈)
- `Spring.` → `Bloom.` → `봄, 천천히.` (영문/국문 혼용)
- `Two.` → `Friends.` → `03.14.` (콜라보 톤)

### 잘못된 사례

- `안녕하세요.` → `우리 브랜드는.` → `사랑합니다.` (감탄·평서문, 시리즈 호흡 깨짐)
- `Quiet.` → `Quiet.` → `Quiet.` (같은 단어 반복, 시리즈가 아님)
- `Spring.` → `Summer.` → `Fall.` (시즌 시리즈는 한 시즌 안에 머물러야 함)
- `BUY` → `BUY NOW` → `BUY!!!` (광고 카피, 포엣코어 톤 아님)

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 캐러셀이 인스타그램 광고처럼 보입니다.

- [ ] 카드 2장 또는 4장 이상 → 정확히 3장으로
- [ ] 외부 이미지 사용 → 그라데이션 + (선택) SVG 실루엣으로
- [ ] 헤드라인이 광고 카피 (`최대 50% 할인!`, `오늘만 사세요`) → 포엣코어 한 단어로
- [ ] 카드 3장 모두 같은 색조 → 도미넌트 컬러 3종 (시즌 컬러 또는 시간대)으로 분기
- [ ] 헤드라인을 mono 폰트로 작성 → 디스플레이 폰트(세리프 또는 디스플레이 산세리프)로
- [ ] 캡션을 디스플레이 폰트로 작성 → mono로
- [ ] CTA가 없거나 카드 1·2에 있음 → 정확히 카드 3에만

## K-패션 특화 검수 (선택)

- [ ] 영문 산업용어 그대로 (`SS`, `FW`, `DROP`, `LOOK`, `LOOKBOOK`, `CAMPAIGN`, `COLLAB`, `SERIES`, `LIMITED`)
- [ ] 시즌 코드 일관성 (`27SS`, `27SS · DROP 02`, `27SS · CAPSULE`)
- [ ] 캡션 한국어 보조 자막이 명사구 종결 (`정제된 하루, 그 자체.`, `회원만, 한정 수량.`)
- [ ] 마지막 카드 CTA가 행동 단어 (`Pre-order.`, `Shop.`, `Lookbook.`, `Link in bio.`)
- [ ] 카드 chip 안 워드마크가 브랜드의 정식 영문 표기 (`MATIN KIM`, `WACKYWILLY`, `MARDI MERCREDI`)
- [ ] 카드별 메타가 정확 — 모델·사진·발매일·채널이 실제 정보 (플레이스홀더 금지)

## 캐러셀의 5대 사용처

이 캐러셀이 다음 5개 자리에 모두 어울리는지 확인:

1. **인스타그램 본 계정 캐러셀** — 1:1 정사각 3장 (기본)
2. **인스타그램 릴스(보조)** — 9:16 비율 재크롭 (첫 장 키비주얼 사용)
3. **무신사 브랜드 페이지 / 29CM 큐레이션** — 첫 장 키비주얼 배너 재활용
4. **카카오톡 친구톡 이미지** — 첫 장 + CTA를 이미지 메시지로
5. **카페24 자사몰 메인 슬라이드** — 3장을 순환 노출

특히 첫 카드는 인스타그램 그리드 미리보기 + 친구톡 이미지 + 자사몰 슬라이드로 가장 많이 재활용되므로 단독으로도 가장 강해야 합니다.
