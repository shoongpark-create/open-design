# K-패션 내부 위키 / 운영 매뉴얼 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 상단바에 브랜드 워드마크 + 검색 인풋(`⌘K`) + 우측 메타(버전 / 시즌 갱신) 모두 표기
- [ ] 좌측 사이드 네비에 **3~5개 그룹** + 그룹당 **3~6개 링크** + 현재 페이지 1개 액티브 상태
- [ ] 그룹 라벨이 mono + uppercase + letter-spacing (`.group-label` 스타일)
- [ ] 중앙 article에 크럼 (`위키 › 그룹 › 페이지`) + H1 + lede 문단 (60자 이상)
- [ ] **본문 H2 4~5개**. 각 H2에 anchor `id` 부여 → 우측 TOC와 연결
- [ ] 본문에 **코드 블록 최소 1개** — 한국어 주석 포함 (SKU 코드 패턴 / 명령어 / 토큰 JSON 등)
- [ ] 본문에 **표 1개 이상** — 카테고리 매핑 / BTA 분포 / 발주 일정 / 디자인 토큰 등
- [ ] 본문에 **콜아웃 1~2개** — 라벨은 한국어 (`참고` / `주의` / `중요` / `금지`)
- [ ] 우측 TOC에 H2 4~5개 anchors + 현재 활성 1개
- [ ] 페이저 (이전/다음 페이지 2개) 본문 하단에 존재
- [ ] 모든 색상은 `:root` 토큰에서 옴 — 임의 hex 금지
- [ ] 코드 블록은 mono 토큰 + `--code-bg` surface fill (일반 `monospace` 금지)

## P1 — 강력 권장

- [ ] 본문 폰트 `Pretendard Variable`, 디스플레이는 `--font-display-report`
- [ ] 본문 텍스트가 **60~75자 라인 길이**에서 wrap (`max-width: 760px`)
- [ ] SKU 코드 패턴 예시는 K-패션 표준 — `[브랜드]-[시즌]-[카테고리]-[연번]` (예: `WW-27SS-OUT-005`, 말미 `Q` = QR, `C` = 캐리오버)
- [ ] 산업용어 유지 — SKU / BTA / OEM / MOQ / LOT / QR / SPOT / 정상판매율 / 사입가율 / 알림톡 / 무신사 베스트
- [ ] 콜아웃에 **실제 K-패션 운영 시나리오** 명시 — 예: "베스트 진입 SKU는 자사몰 sell-out 위험 → 노출 조정"
- [ ] 액센트 컬러 절제 — 현재 네비 아이템 + 본문 링크 + 콜아웃 보더 정도. body 텍스트 액센트 금지

## P2 — 다듬기

- [ ] 1280w에서 3컬럼 모두 표시, 1100w 이하에서 우측 TOC 사라지고 2컬럼, 760w 이하에서 사이드 네비도 사라지고 1컬럼 (CSS만으로 OK)
- [ ] 사이드바 sticky + TOC sticky가 자연스럽게 작동 (상단바 따라 top offset 정합)
- [ ] H2 `scroll-margin-top` 적용 — anchor 점프 시 헤더에 가려지지 않음
- [ ] 코드 블록의 한국어 주석이 `#`로 시작
- [ ] 페이저에 이전/다음 페이지명이 실제 사이드바 링크와 정합

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 사이드바 그룹 1개 → 최소 3개로 보강 (위키 카테고리 구조 부재)
- [ ] 본문 lede 문단이 30자 미만 → 60자+ 의도 / 청중 / 범위 문장으로 확장
- [ ] H2 1~2개만 → 4~5개로 보강. 한 페이지에 단편 정보가 아닌 운영 전체 사이클이 들어가야 함
- [ ] 코드 블록이 영문 placeholder (`example.com`) → 실제 K-패션 도메인·SKU 코드 사용
- [ ] 표가 영문 헤더 (`Category / Quantity`) → 한국어 헤더 (`카테고리 / 수량`)

## K-패션 특화 검수 (선택)

- [ ] 카테고리 명칭이 K-영캐주얼 표준 — UNI / WOMEN / ACC / KIDS (Men · Women만 쓰지 말 것)
- [ ] 채널 표기 — 무신사 / 29CM / W컨셉 / 자사몰 / 한섬몰 / 지그재그 (영문 직역 금지)
- [ ] 자사몰 솔루션 표기 — 카페24 / 쇼피파이 / 메이크샵
- [ ] 시즌 코드 — 27SS / 26FW / S1 (5-6월) / S2 (7월) / S3 (8월) / S4 (9월)
- [ ] 결재선 / R&R 명시 — 디자인실장 / MD실장 / 영업기획팀 / 생산실장 / 마케팅실장 / 대표
- [ ] 콜아웃에 실제 한국 패션기업 운영 표준 — "베스트 진입 시 자사몰 마진율 보호", "QC 결함률 5%+ 시 본생산 정지"
