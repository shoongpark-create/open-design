무신사 입점 매뉴얼

신규 디자이너 · MD · 영업기획 입사자가 1주차에 끝까지 읽고, 디자인 실장과 1:1 확인을 마치는 공식 문서. 와키윌리의 무신사 셀러센터 가입부터 정산까지 운영 전 과정을 5개 섹션으로 정리.

1. 무신사 셀러센터 가입 + 초기 설정

와키윌리는 2024년 11월 무신사 입점 완료. 사업자등록증 + 통신판매업신고증 + 상표권등록증을 제출하고, 영업기획팀(지훈)이 셀러센터 마스터 계정을 관리한다. 신규 입사자에게는 서브 계정을 발급한다.

# 셀러센터 서브 계정 발급 절차 (영업기획팀에 요청)
이메일 · @wackywilly.com 도메인 필수
권한 종류 · 상품 등록 (디자이너/MD) · 운영 (영업기획) · 정산 (재무)
초대 메일 24시간 내 가입 완료
참고
무신사 셀러센터는 PC 전용. 모바일 셀러 앱은 알림 확인 용도로만 사용하세요. 상품 등록/수정은 반드시 PC에서 진행.

2. 상품 등록 SOP

무신사 상품 등록은 와키윌리 자사몰 등록 직후 진행한다. SKU 마스터 데이터는 사내 ERP에서 export 후, 무신사 표준 양식으로 변환 후 일괄 업로드.

SKU 명명 규칙

모든 채널 공통 SKU 코드는 다음 패턴을 따른다. 무신사 등록 시에도 동일 코드를 사용해야 자사몰 ↔ 무신사 재고 동기화가 가능.

# SKU 코드 패턴
[브랜드]-[시즌]-[카테고리]-[연번]

예시
WW-27SS-TOP-011    # 와키윌리 27SS 상의 11번
WW-27SS-OUT-005Q   # QR 발주분 (말미 Q)
WW-26FW-BTM-002C   # 캐리오버 SKU (말미 C)

3. 무신사 베스트 진입 로직

무신사 베스트 알고리즘은 (1) 판매량 + (2) 트래픽 + (3) 리뷰 평점 + (4) 신상품 가중치의 조합으로 결정된다. 신상품은 발매 후 4주간 가중치를 받기 때문에, 와키윌리는 시즌 키 아이템을 무신사 발매와 동시에 인스타·알림톡 캠페인 push 하는 전략을 사용한다.

주의
베스트 진입 SKU는 자사몰에서 동시 sell-out 위험이 높음. 무신사 베스트 진입 신호가 오면 영업기획팀이 자사몰 노출 비중을 조정(메인 배너 → 하단)해 채널 균형을 맞춘다. 마진율 35%+인 자사몰 비중을 보호하는 운영 표준.

4. 리뷰 · Q&A 응대 SOP

리뷰는 24시간 내 응답 표준. Q&A는 48시간 내 응답이 무신사 셀러 등급에 영향. 응대 톤은 다음 표준 카피를 참고:

# 긍정 리뷰 응답 표준
"○○님, 좋은 리뷰 감사합니다. 27SS 시즌도 윌리와 함께 해주세요. — WACKYWILLY"

# 부정 리뷰 응답 표준 (사이즈/핏 관련)
"○○님, 불편을 드려 죄송합니다. 사이즈 가이드를 다시 확인 후
교환·환불 안내드리겠습니다. 채널톡으로 별도 컨택 부탁드려요. — WACKYWILLY"

# Q&A 응답 표준 (배송 문의)
"입고 일정 안내드립니다. 평일 14시 이전 결제 시 당일 발송,
이후 익영업일 발송. 도서산간 지역은 +1~2일 추가. — WACKYWILLY"

5. 정산 일정 · 수수료 구조

무신사 정산은 월 1회 · 매월 15일 · 전월 21일 ~ 당월 20일 매출 기준. 수수료는 카테고리별 차이(15~25%) + 무신사 PG 수수료 + 적립금 차감 후 입금. 정산 명세서는 재무팀이 다운로드 후 사내 ERP에 반영.

QR 발주분(말미 Q)과 캐리오버(말미 C)는 정산 명세서에서 동일 SKU로 합산되므로, ERP에서는 별도 코드로 관리한다. 다음 페이지 수수료 구조에서 상세 표 참조.
