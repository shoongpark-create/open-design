# K-패션 위클리 매출 리포트 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 슬라이드 **정확히 8장** (7장·9장 금지). 각 슬라이드에 `01/08 ~ 08/08` 페이지 번호
- [ ] 8장 표준 순서 유지 — 표지 → 헤드라인 숫자 → 무신사 베스트 → 인기 SKU → QR/SPOT 결정 → KPI 차트 → 다음 주 액션 → 클로징
- [ ] 가로 스냅 스크롤 (`scroll-snap-type: x mandatory`) + 도트 네비 8개 + 화살표 키 핸들러 동작
- [ ] 표지에 브랜드 + 시즌 + W주차 + 발행일(요일) + 작성자(영업기획팀 + 이름) 5종 모두 표기
- [ ] 헤드라인 슬라이드에 큰 숫자(120~240px) 1개 + WoW/MoM 단위 명시
- [ ] 무신사 베스트 슬라이드에 **진입 SKU + 이탈 SKU 모두** 표 형태로
- [ ] 인기 SKU TOP5 표에 SKU 코드 + BTA + 판매수량 + GMV + 정판율 + QR 후보 6개 컬럼
- [ ] QR/SPOT 결정 슬라이드는 **단순 보고가 아닌 결정** — 발주 수량 + 데드라인 + 데시전 오너 3종 모두
- [ ] 다음 주 액션 슬라이드는 부서 3개 (디자인실 / 마케팅실 / 생산실 또는 MD실) 카드 + 각 카드 오너 명시
- [ ] 클로징 슬라이드에 다음 리포트 발행 일자 + Confidential 표시 + 작성자 시그니처
- [ ] 모든 색상은 `:root` 토큰. 임의 hex 금지

## P1 — 강력 권장

- [ ] 헤드라인 숫자 색상이 톤과 일치 — 호조 = `var(--accent)`, 부진 = `var(--bad)`
- [ ] 한국 K-패션 수치 현실치 — 정판율 60~85%, 주간 GMV WoW ±30%p 이내
- [ ] 무신사 베스트 진입 1~3 / 이탈 0~2 정도가 자연스러움 (대량 진입은 비현실)
- [ ] QR 발주 수량 1,000~2,000장, SPOT 300~800장 범위 (한국 영캐주얼 표준)
- [ ] BTA 태그 색상 — Basic 그레이 / Trend 블루 / Accent 액센트(브랜드 키 컬러)
- [ ] 액션 카드는 행동 동사 — "광고 예산 +500만원 요청", "컬러 +1 추가 검토"
- [ ] 폰트 디스플레이 = `--font-display-report` (운영 톤)
- [ ] 작성자 이메일 도메인이 브랜드 도메인과 일치 (`@wackywilly.kr`)

## P2 — 다듬기

- [ ] 차트는 인라인 SVG (외부 라이브러리 금지)
- [ ] 도트 네비 active 상태가 페이지 번호와 일치
- [ ] 모바일 900px 폭에서 차트 + 액션 1단으로 폴백
- [ ] 시즌 코드 표기 일관 (`27SS W12`, `5/13 ~ 5/19`)
- [ ] 한국어 요일 표기 (`5/20 (월)`) + 영문 W주차 (`W12`)

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 슬라이드 6장 이하 → 8장으로 확장 (필수 슬라이드 누락)
- [ ] QR 결정에 발주 수량·데드라인·오너 누락 → 추가
- [ ] 액션 슬라이드에 부서 오너 누락 → "오너 · 디자인실 민재 실장" 형식으로 추가
- [ ] 헤드라인 숫자가 작고 본문 톤 → 120~240px 큰 숫자로
- [ ] 무신사·29CM 영문 직역 → 한국 표기
- [ ] 작성자 정보 누락 → 영업기획팀 + 이름 + 이메일 추가

## K-패션 특화 검수 (선택)

- [ ] 시즌 표기 정합 (`27SS W12` = 27SS 시즌의 12주차)
- [ ] 채널 표기 한국 표준 — 무신사 / 29CM / W컨셉 / 자사몰 / 한섬몰
- [ ] QR / SPOT 결정의 차이가 명확 — QR = 추가 발주, SPOT = 보강 발주 (수량 적음)
- [ ] 캐리오버 SKU에 `WW-26FW-XXX` 같은 전 시즌 코드 사용
- [ ] 영업기획 → MD실 → 디자인실 → 마케팅실 → 생산실 R&R 흐름 명확
- [ ] 다음 리포트 발행 일자는 7일 후 같은 요일(월요일)
