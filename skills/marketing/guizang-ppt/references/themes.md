# 컬러 테마 프리셋 (K-패션 판)

5개의 사전 조합 컬러 팔레트로 "전자 매거진 × 전자잉크" 미감을 보장합니다. **자유 hex 커스텀 금지** — 컬러 조합이 어긋나면 화면이 즉시 망가짐. 아래 5개 프리셋에서만 선택.

원본 `guizang-ppt-skill`의 5개 테마를 그대로 사용 — K-패션 시즌 합본·콜라보 제안서에도 충분히 적합. 시즌·캠페인 강조 컬러는 `tweaks` 스킬의 `ACCENT_PRESETS`로 별도 오버라이드.

---

## 사용 방법

1. 사용자에게 선택 요청 (또는 콘텐츠 기반 추천)
2. `assets/template.html`의 `<style>` 블록 오픈
3. 시작 부분의 `:root{` 블록 찾기
4. "테마 컬러" 주석이 달린 다음 줄들 **전체 교체**: `--ink` / `--ink-rgb` / `--paper` / `--paper-rgb` / `--paper-tint` / `--ink-tint`
5. 다른 CSS는 `var(--...)` 사용 — 추가 변경 불필요

---

## 🖋 잉크 클래식 (Monocle 기본)

**적합**: 일반 발표, 시즌 합본 덱, 콜라보 제안서, 어디서나 안전한 기본.
**톤**: 순수 잉크 블랙 + 따뜻한 베이지. 매거진감 최강, Monocle / Apricot / A Book Apart 톤.

K-패션 사용 예: 와키윌리 27SS 시즌 합본 (사내 종합), 일반 콜라보 제안.

```css
--ink:#0a0a0b;
--ink-rgb:10,10,11;
--paper:#f1efea;
--paper-rgb:241,239,234;
--paper-tint:#e8e5de;
--ink-tint:#18181a;
```

---

## 🌊 인디고 자기 (Indigo Porcelain)

**적합**: 테크·연구·데이터 발표, 엔지니어 컬처, 심도 콘텐츠, 기술 발표회. K-패션에서는 **IR 자료 / 매출 결산 발표 / 투자자 미팅**에 적합.
**톤**: 깊은 인디고 + 자기 백색. 차분·이성적·심도. 학술지 또는 청화백자.

K-패션 사용 예: 와키윌리 시리즈 A IR 자료, 27SS 매출 결산 + 28SS 아웃룩 (대표 발표).

```css
--ink:#0a1f3d;
--ink-rgb:10,31,61;
--paper:#f1f3f5;
--paper-rgb:241,243,245;
--paper-tint:#e4e8ec;
--ink-tint:#152a4a;
```

## 🌿 포레스트 잉크 (Forest Ink)

**적합**: 자연·지속가능·문화·비픽션 콘텐츠. K-패션에서는 **소재 개발 스토리 / 지속가능 패션 발표 / 라이프스타일 캠페인** 발표.
**톤**: 깊은 숲 그린 + 아이보리. 안정감 + 숨결. 옛 *National Geographic* 톤.

K-패션 사용 예: 린넨 블렌드 소재 개발 발표, 마르디 메크르디 라이프스타일 캠페인.

```css
--ink:#1a2e1f;
--ink-rgb:26,46,31;
--paper:#f5f1e8;
--paper-rgb:245,241,232;
--paper-tint:#ece7da;
--ink-tint:#253d2c;
```

---

## 🍂 카프 페이퍼 (Kraft Paper)

**적합**: 노스탤지어·인문·독서·역사·문학 발표, 독립 매거진, 핸드메이드 브랜드.
**톤**: 깊은 갈색 + 따뜻한 베이지. 카프 봉투 또는 옛 노트 톤. 따뜻 + 시대감.

K-패션 사용 예: 무신사 헤리티지 컬렉션, 인디 브랜드 매거진 인터뷰, 브랜드 아카이브 발표.

```css
--ink:#2a1e13;
--ink-rgb:42,30,19;
--paper:#eedfc7;
--paper-rgb:238,223,199;
--paper-tint:#e0d0b6;
--ink-tint:#3a2a1d;
```

---

## 🌙 듄 (Dune)

**적합**: 아트·디자인·창의·패션 발표, 갤러리 매뉴얼, 미감 우선의 사적 발표회.
**톤**: 차콜 그레이 + 모래색. 절제·고급·중성. 사막 황혼 또는 건축 디자인 아카이브.

K-패션 사용 예: 아더에러 콜라보 제안서, 준지 라인 발표, 컨템포러리 콜라보, 브랜드 아카이브 전시.

```css
--ink:#1f1a14;
--ink-rgb:31,26,20;
--paper:#f0e6d2;
--paper-rgb:240,230,210;
--paper-tint:#e3d7bf;
--ink-tint:#2d2620;
```

## 전환 원칙

- **한 덱에 한 테마** — 중간 변경 금지
- WebGL 셰이더의 기본 컬러(티타늄 색분산 / 실버 플로우)는 5개 테마 모두에 호환 (검증됨)
- `currentColor` 기반 border / icon은 section 텍스트 컬러에 자동 적용 — 별도 조정 불필요
- 테마 선택 후 `<title>` 텍스트와 `chrome` 카피로 테마 의미 강화 가능 (예: 카프 페이퍼에 "Vol.03 · 가을")

## ❌ 금지 사항

- ❌ **혼합 금지** (예: ink는 잉크 클래식, paper는 듄) — 완전 시각 충돌
- ❌ **사용자 임의 hex 값 금지** — 정중히 거절하고 5개 프리셋 제시
- ❌ **template.html의 다른 컬러 직접 수정 금지** — 모든 rgba는 var() 사용, `:root`만 한 곳에서 변경

테마 선택 후 스킬 대화에서 사용자에게 알려주세요: "🖋 잉크 클래식 / 🌊 인디고 자기 ..." 사용 중. 프로젝트 기록에 명시해 다음 반복에서 일관성 유지.
