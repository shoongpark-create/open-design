# 매거진 방향 (Magazine Directions)

5개의 **사전 정의 방향**. 각 방향은 "어느 테마 컬러 / 어떤 레이아웃 / 슬라이드 몇 장 / chrome 카피 톤"을 패키지로 포함. 6개 명확화 질문에서 5개의 무관한 선택을 주지 않도록 함.

> 영감 출처: [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design)의 "20 design philosophies × 5 streams"를 매거진풍 5개로 압축. 각 방향은 `themes.md`의 한 세트 + `layouts.md`의 일부 조합과 매핑.

원본은 중국풍 매거진 방향. 이 K-패션 판은 **각 방향에 K-패션 사용 시나리오** 추가.

---

## 이 문서 사용 시점

SKILL.md `Step 1 · 필요 사항 정리` 시작 시 **먼저 5개 방향에서 사용자에게 하나 선택하게 하기**, 그 후 컬러 / 시간 / 받는 사람 / 아우트라인 질문. 흐름:

```
1. 사용자가 "발표 PPT 만들고 싶다"고 함
2. agent가 5개 방향 소개 (아래 1줄 요약 복사)
3. 사용자가 방향 선택 (또는 "모르겠다, 추천")
4. agent가 선택된 방향으로 "테마 컬러"와 "슬라이드 수" 두 질문 답하고 나머지 4개 진행
```

**하드 규칙**: 방향은 아래 5개에서만 선택, 혼합 금지. 혼합 = huashu-design에서 검증된 실패 경로(브랜드 자산 규약 v1). 사용자가 5개 모두에 불만족하면 가장 가까운 것 권유하고 `chrome` / `kicker`에서 약간 톤 커스텀 허용, **컬러는 절대 변경 금지**.

## 1. Monocle Editorial · 국제 매거진 톤 ✦ 기본 추천

**키워드**: 절제, 지식감, 국제적, *taste* 있음

| 레시피 | 선택 |
|---|---|
| 테마 컬러 | 🖋 잉크 클래식 |
| 권장 슬라이드 수 | 18-24페이지 (60% non-hero / 40% hero) |
| 주력 레이아웃 | **1 표지 / 2 챕터 막 / 4 좌문 우상 / 8 대인용 / 10 도판+사이드** |
| Chrome 카피 | `Vol.04 · 27SS 2026` / `Act II · 12 / 24` / `wackywilly.kr · 2026.05` |
| Kicker 톤 | 짧은 영문 + 중점: `THE TWIST` / `BUT` / `MAY.` |
| Foot 카피 | `Page 12 · 27SS 시즌 합본` |

**K-패션 사용 시나리오**:
- 시즌 합본 (사내 종합)
- 일반 콜라보 제안서
- 분기 브랜드 발표
- 매장 입점 PR 덱
- 브랜드 컬처 외부 발표

**부적합**: 기술 심도 보고 (밀도 부족), 데이터 표 많은 발주 결산 회고 (적합한 레이아웃 없음).

**비주얼 앵커**: *Monocle* / *Apartamento* / *Kinfolk* / 마뗑킴 시즌 룩북.

## 2. WIRED Tech · 데이터 + 엔지니어링

**키워드**: 하드 데이터, 파이프라인, 비교, 미래감

| 레시피 | 선택 |
|---|---|
| 테마 컬러 | 🌊 인디고 자기 |
| 권장 슬라이드 수 | 14-18페이지 (가볍고 데이터 밀도 높음) |
| 주력 레이아웃 | **1 표지 / 3 데이터 대자보 / 6 Pipeline / 7 질문 / 9 Before/After** |
| Chrome 카피 | `Q2 / 2026 · 27SS Recap` / `Data · 03` / `MD Notes` |
| Kicker 톤 | 전부 대문자 + 숫자: `+18% YoY` / `RUNTIME 04` / `CASE 02` |
| Foot 카피 | `Page 03 · 정판율 벤치` / `methodology footnote` |

**K-패션 사용 시나리오**:
- IR 자료 (시리즈 A/B 투자 유치)
- 매출 결산 + 시즌 아웃룩 (대표 발표)
- 분기 데이터 리뷰 (이사회용)
- 무신사 입점 데이터 PR
- 글로벌 진출 IR 자료

**부적합**: 인문 톤 금구 발표 (너무 차가움), 아트 브랜드 (온도 부족).

**비주얼 앵커**: *WIRED* 장문판 / *MIT Technology Review* / *The Pudding* / *Stripe Press* / 무신사 IR 자료.

**특별 권장**: 각 stat-card의 `stat-label`은 영문 모노 (WIRED 톤 핵심). 숫자는 천 단위 콤마 없이 `억` / `만` / `%` / `×` 단축형 사용.

## 3. Kinfolk Slow · 슬로우 라이프 / 인문

**키워드**: 여백, 세리프, 온도, 사적 발표

| 레시피 | 선택 |
|---|---|
| 테마 컬러 | 🍂 카프 페이퍼 |
| 권장 슬라이드 수 | 9-12페이지 (느림, 비움, 저밀도) |
| 주력 레이아웃 | **1 표지 / 4 좌문 우상 / 8 대인용 / 10 도판+사이드 / 2 챕터 막** |
| Chrome 카피 | `Vol.07 · Autumn` / `한 통의 편지 · 03` / `Notes from Seoul` |
| Kicker 톤 | 한글 짧은 절 + 구두점: "친구에게." / "늦은 봄." / "Letter Three" |
| Foot 카피 | `Page 03 · Letter Three` / `2026 · Spring Issue` |

**K-패션 사용 시나리오**:
- 라이프스타일 캠페인 발표 (마르디 톤)
- 브랜드 매거진 인터뷰
- 디자이너 개인 에세이 발표
- 시즌 컨셉 보드 외부 미디어 공개
- 매장 오프닝 사적 초대장

**부적합**: 발주·매출 결산 (너무 느림), 기술 발표 (너무 부드러움), 정성 데이터 (정보 밀도 부족).

**비주얼 앵커**: *Kinfolk* / *The Gentlewoman* / *Cereal* / *Drift Magazine* / 마르디 메크르디 컨셉 보드.

**특별 권장**:
- **슬라이드 10페이지 이하로 의도적 압축** — Kinfolk 핵심은 "less is more", 가득 채우지 마세요
- 레이아웃 8(대인용)과 10(도판+사이드) 대량 사용
- 레이아웃 3(데이터 대자보) 금지 — 톤 충돌
- `<title>` 텍스트, 챕터명, kicker 모두 세리프 + 한글 짧은 절

## 4. Domus Architectural · 건축 / 공간감

**키워드**: 스케일, 기하, 비대칭, 절제된 과시

| 레시피 | 선택 |
|---|---|
| 테마 컬러 | 🌙 듄 |
| 권장 슬라이드 수 | 12-18페이지 (중간 밀도, 강한 비주얼) |
| 주력 레이아웃 | **1 표지 / 2 챕터 막 / 5 이미지 그리드 / 9 Before/After / 10 도판+사이드** |
| Chrome 카피 | `Spazio 09 · Project File` / `Plan · 03` / `Fig.4` |
| Kicker 톤 | 숫자 + 카테고리: `PROJECT 04` / `SECTION B` / `FIGURE 12` |
| Foot 카피 | `Page 09 · West Wing` / `1:200 scale` |

**K-패션 사용 시나리오**:
- 아더에러·준지 같은 컨템포러리 콜라보 제안
- 매장 디자인 / 플래그십 발표
- 시즌 룩북 갤러리 전시 톤
- 브랜드 아카이브 / portfolio 전시
- 패션 위크 / 외부 디자이너 PR

**부적합**: 금구·매니페스토 발표 (너무 딱딱함), 기술 deep dive (파이프라인 약함).

**비주얼 앵커**: *Domus* / *Apartamento* / *Mark Magazine* / *Pin-Up* / 아더에러 매장 가이드.

**특별 권장**:
- **모든 hero 페이지에 60% 여백 확보** — 가득 채우지 마세요, 건축감은 호흡에서 옴
- 레이아웃 5(이미지 그리드) 사용 시 **큰 이미지 4장만**, 작은 이미지 6장 금지
- `chrome` 카피는 차분, 영문 + 숫자만

## 5. Lab / Reference · 학술 + 공예 매뉴얼

**키워드**: 절제, 도표 있음, 재현 가능, 엔지니어 친화

| 레시피 | 선택 |
|---|---|
| 테마 컬러 | 🌿 포레스트 잉크 |
| 권장 슬라이드 수 | 16-24페이지 (밀도 높음, 도표 있음) |

| Kicker 톤 | 번호: `§ 3.2` / `Ref. 04` / `Method 01` |
| Foot 카피 | `Page 12 · 3.2 Calibration` / `appendix A` |

**K-패션 사용 시나리오**:
- 소재 개발 스토리 (린넨 블렌드 / 캐시미어 블렌드)
- 핏 시스템 발표 (한국적 핏 표준화)
- 지속가능 패션 발표 (재활용 소재)
- 디자인 시스템 문서화 발표

**부적합**: 상업 발표 (너무 차분), 마케팅 캠페인 (catchy 부족).

**비주얼 앵커**: *National Geographic* (구판) / *Hand-Eye Magazine* / *Nautilus* / *MIT Press* book layouts.

**특별 권장**:
- `meta-row` 다용해 출처·방법·인용 명시
- 다른 방향보다 **`<figcaption class="img-cap">`로 그림에 더 자주 번호 매기기**
- `kicker`는 § 챕터 번호, 감탄문 금지

## 의사결정 기록 (생성 전 필수)

방향 선택 후 **프로젝트 폴더에 `시즌-기록.md` 생성·갱신** (또는 `아우트라인-v1.md`), 첫 행에 명시:

```markdown
# [발표 제목] · 시즌 기록

- 방향(Direction): **Monocle Editorial** (from `references/styles.md`)
- 테마 컬러(Theme): 🖋 잉크 클래식
- 받는 사람: 사내 종합 (디자인 + MD + 마케팅 + 대표)
- 시간: 25분 · 약 22 슬라이드
- Chrome 톤: Vol.04 / Act II / 12 of 22
- Kicker 톤: 짧은 영문 + 중점
```

이후 반복마다 방향 조정 시 이 섹션 업데이트. **중간에 방향 변경 금지** — 5개 방향 간 "어조" 차이가 생각보다 크므로 섞으면 찢어짐.

## ❌ 금지 사항

- ❌ 5개 방향의 레이아웃 선택 혼합 (예: Monocle + Layout 6 Pipeline 다용 + Kinfolk 톤 chrome) — 산만
- ❌ 6번째 방향 직접 만들기 ("'테크 + 인문' 톤 원함") — 정중히 가장 가까운 것 권유, 혼합 역사 실패율 매우 높음
- ❌ 중도 방향 변경 (예: 8페이지 만든 뒤 "Kinfolk 더 좋겠다") — 앞 7페이지 폐기, 전부 다시 또는 원 방향 끝까지
- ❌ 해당 방향에 안 맞는 레이아웃 시간 낭비 (예: Kinfolk에 Layout 6 Pipeline 4페이지) — 방향 잘못 선택 신호

## ✅ 해야 할 것

- ✅ 5개 방향에서만 선택, 선택 후 나머지 5개 명확화 질문에 사용
- ✅ `시즌-기록.md` 첫 행에 방향 명시, 전 과정 불변
- ✅ chrome / kicker / foot 세 텍스트 슬롯이 방향을 "대변" — 방향 식별의 절반 담당
- ✅ 불확실하면 **기본 Monocle Editorial** — 5개 중 실패 확률 최저
