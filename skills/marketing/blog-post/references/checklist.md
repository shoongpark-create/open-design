# K-패션 매거진 컬럼 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 타입 위계가 분명 — H1(헤드라인) > H2(섹션 구분자) > 본문. 풀쿼트는 H1과 경쟁하지 않는 크기 (~26~28px)
- [ ] **본문 600자 이상**, 4~6개 H2 섹션 존재
- [ ] **풀쿼트 1개 + 피겨 1개 + 리스트 1개 + 인라인 인용 1개** 모두 포함 (없는 항목 금지)
- [ ] 본문 한 줄당 60~75자 (한국어 약 40~55자) 가독 폭. `max-width: 720px` 유지
- [ ] 카피 톤이 **포엣코어** — 직설 스펙(`코튼 100%, XS~XL`)이 아니라 감각·계절감·디자이너 의도 서술
- [ ] **lorem ipsum 또는 플레이스홀더 카피 금지**. 모든 본문이 진짜 매거진 글
- [ ] 헤드라인이 디스플레이 세리프(Hahmlet, Instrument Serif, 본명조). 시스템 산세리프로 오버라이드 금지
- [ ] 카테고리 아이브로우가 영문 대문자 + mono + letter-spacing (`SEASON STORY · 27SS`)
- [ ] 저자 풋터에 **실제 이름·역할·약력**. `[저자명]` 같은 플레이스홀더 금지
- [ ] 관련 글 3개에 **실제 제목·1줄 발췌·ISO 일자**
- [ ] 외부 이미지 URL 없음 — `.hero-img`, `.figure-img`, `.card-img`는 그라데이션으로

## P1 — 강력 권장

- [ ] 페이지가 **매거진처럼 읽힘**. 마케팅 랜딩 페이지가 아님 — CTA 버튼 강조 금지, 본문 안에 `<button>` 사용 금지
- [ ] 액센트 컬러는 **최대 2회** (카테고리 아이브로우 + 풀쿼트 보더, 또는 풀쿼트 보더 + 본문 내 단일 링크)
- [ ] 데크(subhead)가 헤드라인의 1/3 크기 (~20px). 이탤릭 세리프
- [ ] 바이라인이 저자명 + 역할 + ISO 일자(`2027.04.10`). mono 폰트 메타 사용
- [ ] 히어로 이미지 캡션이 mono 영문 (`27SS LOOKBOOK · 모델 김혜준 · 사진 이호인`)
- [ ] 풀쿼트 인용이 디자이너/대표 발언 1~2 문장. `cite`로 발화자 표시
- [ ] H2 섹션 구분자가 **번호 또는 키워드** 형식 (`첫번째 — 외치지 않는 봄`, `LOOK 01 — 아침의 옷`)
- [ ] 드롭 캡(`::first-letter`)은 에디토리얼/세리프 톤일 때만. 영캐주얼·위트 톤(아더에러·와키윌리)에서는 `.body.dropcap` 클래스 제거

## P2 — 다듬기

- [ ] 본문 첫 단락이 시즌 무드·계절감을 짧게 설정. 디자이너 노트 톤
- [ ] 인라인 `<blockquote>` 인용이 한 문장. 본문 마지막 또는 H2 직전에 위치
- [ ] 리스트(`<ol>` 또는 `<ul>`)가 컬러 팔레트·LOOK 리스트·약속 같은 구체적 항목
- [ ] 관련 글 3개가 **같은 시즌의 다른 에세이·인터뷰·룩북**으로 묶임
- [ ] 모바일 720px 폭에서 풀쿼트 좌측 보더가 유지되고 폰트가 한 단계 축소

## 영문 산업용어 / 매거진 톤 검수

- [ ] 영문 산업용어는 그대로 (`SS`, `FW`, `LOOKBOOK`, `BTA`, `DROP`, `COLLAB`, `CAPSULE`)
- [ ] 매거진 인용은 영문 워드마크 (`VOGUE KOREA`, `W KOREA`, `DAZED KOREA`, `1stLook`)
- [ ] 시즌 코드 표기 일관성 (`27SS`, `27SS S2 판기`)
- [ ] 영문 헤드라인 + 한국어 데크 혼용 가능. 단, 한국어 직역 동시 표기 금지 (`On Spring / 봄에 대해` 같은 형태)
- [ ] 본문 종결이 자연스러운 한국어 (`~한다.`, `~인다.`, `~다.`). 과한 `~이다`체 자제

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 글이 매거진이 아니라 보도자료처럼 보입니다.

- [ ] 본문에 CTA 버튼(`사전예약 시작`)이 강조됨 → 본문 마지막 단락에 텍스트로 일정만 안내
- [ ] H2 섹션이 1~2개 → 4~6개로 확장
- [ ] 풀쿼트 없음 → 디자이너/대표 발언으로 1개 추가
- [ ] 저자가 `에디터` 같은 익명 → 실제 이름·역할 명시
- [ ] 헤드라인이 광고 카피 톤 (`!!! 절대 놓치지 마세요`) → 매거진 1문장으로 단정

## K-패션 특화 검수 (선택)

- [ ] 본문 톤이 W Korea·Dazed Korea·Vogue Korea 매거진 톤
- [ ] 카테고리 표기 (`SEASON STORY`, `DESIGNER NOTE`, `LOOKBOOK ESSAY`, `COLLAB BEHIND`)
- [ ] 시즌 사이클 정합성 — 시즌 룩북 공개 시점(시즌 시작 1~2개월 전) 또는 시즌 중반(실착 후기, 스타일링 가이드)
- [ ] 발행 채널 의식 — 자사몰 JOURNAL / 무신사 매거진 / 29CM 매거진 / 브런치·네이버 블로그 중 어디로 발행할지 카피 톤이 맞음
- [ ] 본문 한국어가 너무 딱딱한 `~한다`, `~이다`로 빠지지 않음. 매거진 호흡 (`~다`, `~인다`, `~한다`)
