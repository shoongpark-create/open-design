# K-패션 시즌 OKR 트래커 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 시즌 배너에 시즌 크럼(`WACKYWILLY · 27SS · S/S 시즌 · S1 판기`) + 페이지 제목 + lede + 우측 종합 진척률(%) 4종 모두 보유
- [ ] Objective 카드 **정확히 3개** (리듬 C/D 단일 Obj 제외). 4개 이상 금지
- [ ] 각 Obj에 번호 + 한국어 평서문 1문장 본문 + 오너 + 상태 칩 보유
- [ ] Objective 본문은 **"Goal A / Goal B" 같은 플레이스홀더 금지** — 실제 K-패션 KPI 합의 문장으로
- [ ] 각 Obj마다 KR 3개 (리듬 A 기준 총 9개). 리듬 C/D는 KR 5개
- [ ] KR마다 메트릭 + 베이스라인 → 목표 + 진행률 바 + 현재값 4종 모두 보유
- [ ] KR 값은 K-패션 현실치 — 정판율 60~85%, 재고자산회전율 3~20회, GMV 단위 억/만원
- [ ] 상태 칩 3종 (정상 · 주의 · 이탈) 중 최소 2종 등장 — 모두 정상이면 비현실
- [ ] 진행률 바 색상이 상태 칩과 일치 — 정상 green, 주의 amber, 이탈 red
- [ ] 사이드바에 시즌 한눈에 4종 stat + 이번 주 movers + 블로커 콜아웃 모두 보유
- [ ] 모든 색상은 `:root` 토큰. 임의 hex 금지

## P1 — 강력 권장

- [ ] 폰트: 본문 Pretendard, 디스플레이는 `--font-display-report` (운영 톤)
- [ ] Obj 본문은 한 문장, 명사구로 끝나지 않고 평서문 — "끌어올린다", "만든다", "확장한다"
- [ ] 오너 한글 이니셜 — 민재 / 서연 / 윤서 / 지훈 (한국 패션기업 톤)
- [ ] 베이스라인 + 목표 표기는 모노 폰트 + tabular-nums
- [ ] 진행률 % = 현재값 / 목표값 비례 (Obj가 80% 정도면 KR 평균이 80% 근방)
- [ ] 이번 주 movers 3개 항목 — KR 1.1, KR 2.1 같은 ID로 추적
- [ ] 블로커 콜아웃에 데드라인 + 담당 + 결정 사항(SPOT 발주 검토 / 마케팅 예산 +500만원) 명시

## P2 — 다듬기

- [ ] 시즌 종합 진척률(%)이 KR 9개 평균과 정합 (±5%p 이내)
- [ ] 사이드바 sticky 시 메인 영역만 스크롤
- [ ] 모바일 1024px 폭에서 사이드바가 하단으로 폴백, KR 행이 1열로
- [ ] 시즌 코드 표기 일관성 (`27SS`, `S1 판기`, `D-42`)
- [ ] 채널·매거진 영문 표기 (VOGUE KOREA / W KOREA / DAZED KOREA) 유지

## 하드 룰 위반 점검 (anti-pattern)

- [ ] Objective 4개 이상 → 3개로 압축
- [ ] 모든 상태 칩이 '정상'만 → 의도적으로 1개를 '주의' 또는 '이탈'로 변경 (현실성)
- [ ] KR이 정성적 표현 (`브랜드 강화` 같은 문장) → 정량 메트릭 (`정판율 78%`)로 변경
- [ ] 베이스라인 누락 → `베이스라인 72% → 목표 78%` 형식으로 추가
- [ ] 채널 영문 직역(`Musinsa Best`) → 한국 표기(`무신사 베스트`)
- [ ] 블로커가 추상적 (`매출 부진`) → `KR 3.1 윌리 굿즈 매출 ↓ — OEM 입고 지연` 같은 구체

## K-패션 특화 검수 (선택)

- [ ] Obj 1 = 상품 (정판율 / 회전율 / QR 비중) — MD실 + 디자인실 R&R
- [ ] Obj 2 = 채널 (무신사 GMV / 29CM 비중 / 자사몰 회원) — 영업기획 + 이커머스팀 R&R
- [ ] Obj 3 = 브랜드·IP (캐릭터 굿즈 / SNS / 매거진) — 마케팅실 R&R
- [ ] BTA 분포 KR 있다면 Basic 40~50% / Trend 30~40% / Accent 10~20%
- [ ] 시즌 잔여일이 시즌 코드와 일치 (S/S 시즌 5월 시작 → D-150 ~ D-180)
