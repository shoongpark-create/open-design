# K-패션 상품 기획서 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 상단 헤더에 브랜드/시즌 크럼 + 상태 칩(Draft / Review / Approved) + 작성자 + 수정일이 모두 표기됨
- [ ] H1 제목이 한국어 + 영문 혼용 자연 (예: "27SS 시즌 헤드 아이템 · 윌리 그래픽 후디") — 영문 직역 금지
- [ ] 3줄 요약(`.summary`)에 "무엇 / 누구를 위해 / 왜 지금" 세 요소가 모두 포함됨
- [ ] 메타 행에 라인 / 디자이너 / 디자인 리드 / 발매 일정 / 예상 LOT 5개 모두 채워짐
- [ ] 시장·문제 섹션에 **매거진 / 인플루언서 / 회원 VOC 인용** 1건 (`.quote`) 포함 — 단순 자사 데이터만 X
- [ ] 목표·비목표 **2컬럼 모두** 채워짐. 비목표 최소 3개 (다루지 않는 것 명시)
- [ ] 성공 지표 표 **4~6 지표**. 각 지표마다 베이스라인 + 목표 + 측정 방법 3개 컬럼 모두 채워짐
- [ ] 페르소나 / 코디 스토리 **정확히 3개**. 인구 통계(나이, 직업) + 동기 모두 다름
- [ ] 마일스톤 **4단계 카드**: M1 샘플 → M2 LOCK → M3 발주 → M4 입고+캠페인 순서
- [ ] 미결 질문 3개. 각 항목에 **담당자 + 데드라인** 모두 명시
- [ ] 모든 색상은 `:root` 토큰에서 옴 — 임의 hex 금지
- [ ] 통화 단위 원 / 만원 / 억 (USD 금지). LOT/PCS/장 단위 정합

## P1 — 강력 권장

- [ ] 본문 폰트 `Pretendard Variable`, 디스플레이는 `--font-display-report` (운영 기획서 톤). 콜라보·팝업이면 `--font-display-romance` 옵션
- [ ] **정판율 목표 60~85% 범위** — 95% 같은 비현실 금지. 25% 같은 저성과 가정도 금지
- [ ] 페르소나에 **K-아이돌 팬, 디자인 감도 우선, 친구 추천 신규** 같은 3종 다른 동기가 자연스럽게 등장
- [ ] 성공 지표 표에 **무신사 베스트 진입 / 정판율 / 자사몰 D2C 비중 / SNS 해시태그** 같은 K-패션 표준 KPI 우선 사용
- [ ] 마일스톤 4단계 일자가 시즌 사이클 정합 — 시즌 시작 4개월 전 1차 샘플, 3개월 전 LOCK, 2개월 전 발주, 시즌 시작 직전 입고
- [ ] 인용(`.quote`)이 진짜 한국 패션 매거진 워드마크 (VOGUE KOREA / W KOREA / DAZED KOREA / ELLE KOREA / HARPER'S BAZAAR KR)
- [ ] 상태 칩이 결재 단계 정합 — Draft(MD 작성 중) / Review(실장 검토) / Approved(대표 결재)

## P2 — 다듬기

- [ ] 미결 질문에 결재선 책임자(MD실장 / 디자인실장 / 마케팅실장) 직책 표기
- [ ] 시즌 코드 표기 일관성 (`27SS`, `26FW`, `S1 판기`)
- [ ] 액센트 컬러 사용 ≤ 4회 (상태 칩 + 인용 보더 + 마일스톤 뱃지 + 페르소나 강조 정도)
- [ ] 모바일 880px 폭에서 `.problem` / `.goals` 1열, `.timeline` 2x2 폴백 작동
- [ ] 푸터에 문서 버전 + 일자 + 저장 위치(노션 폴더 등) 명시

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 페르소나 1개 또는 2개 → 3개로 보강 (3개 미만이면 타겟 동기 분석 부족)
- [ ] 페르소나 3명 모두 같은 나이대·같은 동기 → 각 페르소나의 차별 동기 명시
- [ ] 마일스톤 3단계 또는 5단계 → 4단계 표준 구조로 정렬
- [ ] 성공 지표에 GMV 한 줄만 → 정판율·회전율·SNS·D2C 비중 등 다축 KPI로 확장
- [ ] 비목표 비어있음 → 최소 3개의 "이번 기획에서 다루지 않는 것" 명시 (기획 범위 명확화)

## K-패션 비즈니스 특화 검수 (선택)

- [ ] 채널 표기가 한국 표준 — 무신사 / 29CM / W컨셉 / 자사몰 / 한섬몰 (영문 직역 금지)
- [ ] OEM 공장 명칭이 자연 — 합천 / 진주 / 대구 / 안양 등 한국 OEM 거점
- [ ] 사입가율·마진율 가정이 한국 패션 표준 (마진율 30~40%, 자사몰 마진율 35%+)
- [ ] 콜라보 / 팝업 기획서의 경우 라이선스 비용·대관료가 예산 표에 명시
- [ ] 결재선이 한국 패션기업 표준 — 디자인실장 → MD실장 → 대표 (콜라보·팝업은 대표 직결재)
