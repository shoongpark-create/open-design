# K-패션 신입 온보딩 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 커버 배너에 신입 이름 + 직무(디자이너/MD/PD/마케터) + 입사일 + **직속 디렉터 + 온보딩 버디** 4개 메타 모두 표기
- [ ] 커버에 **브랜드 환영 문구** 1줄 (브랜드 톤 반영 — 친근형, 사무형 등)
- [ ] 1일차 시간표 **09:00 ~ 17:00 사이 7~8개 슬롯** — 디렉터 킥오프 / IT 셋업 / 버디 커피 / 라인업 시트 투어 / EOD 체크인 표준 포함
- [ ] 1주차 타임라인 월~금 5일, **하루 2개 활동** 표시
- [ ] 1주차에 **현장 활동 최소 1개** — 공장 견학 / 견본 컨퍼(CON) 참관 / 품평회 참관 / 매장 라운드 중 1개 이상
- [ ] 30/60/90일 마일스톤 카드 3개, 각 카드에 **시즌 산출물 단위 목표 3개**
- [ ] **마일스톤 목표가 코드 PR이 아니라 시즌 산출물** — 컨셉 보드 / 라인업 / 컬러 락 / 핏 컨펌 / 룩북 / 발주 보조 등
- [ ] 북마크 리소스 패널에 **K-패션 표준 도구 6개+** — 노션, 슬랙, 피그마, ERP, 무신사 파트너센터, 카페24/쇼피파이
- [ ] 준비 완료 신호 체크리스트 **5개 항목** (시스템 셋업 / 동료 인사 / 첫 산출물 / 회의 흐름 / 질문 편안함)
- [ ] 모든 색상은 `:root` 토큰에서 옴 — 임의 hex 금지
- [ ] 일정 시간 표기 24시간제 (09:00 / 14:00 — K-패션 사내 표준)

## P1 — 강력 권장

- [ ] 디스플레이 폰트가 **세리프(`--font-display-romance`)** — Hahmlet / Grandiflora 권장. 친근 톤 강화
- [ ] 호칭이 **직무명 + 이름** — "디자인실장 김도하", "박지연 디자이너", "장원 수석 디자이너"
- [ ] 30/60/90 마일스톤이 입사 시점의 **시즌 사이클**과 정합 — 6월 입사 = 28FW 컨셉, 1월 입사 = 27SS 본생산, 3월 입사 = 27SS 캠페인
- [ ] 1주차 활동에 **시니어 동행자 명시** — "박지연이 검수", "장하늘 PD 동행"
- [ ] 직무명 한국 패션 표준 — 디자이너 / MD / PD / RMD / VMD / 에디터 / 마케터
- [ ] 준비 완료 체크리스트 일부는 입사 1~2일차 시점에 이미 완료 상태(`.check.done`)로 표시 — 셋업 완료 등
- [ ] 친근 톤 — "오신 것을 환영합니다", "함께해주세요", "차분하게 시작하세요" 같은 한국 사내 등록

## P2 — 다듬기

- [ ] 액센트 컬러가 따뜻한 톤 (테라코타 / 머스타드 / 페일 핑크) — 차가운 액센트는 어색
- [ ] 커버 배경이 다크 (`var(--ink)`) + 텍스트 페이퍼 컬러 대비비 충족
- [ ] 1일차 시간표가 30분 ~ 1.5시간 자연스러운 간격 (모든 슬롯 동일 길이 X)
- [ ] 마일스톤 배지가 일자 + 월 표기 (`Day 30 · 7월`)
- [ ] 푸터에 People Ops / HR / 디자인실 등 작성 부서 + 템플릿 버전 + 업데이트 일자
- [ ] 모바일 900px 폭에서 커버 1열, 1주차 2x2 그리드 폴백 작동

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 1주차 활동이 모두 데스크 작업 (현장 활동 0개) → 공장 견학 / CON 참관 / 품평회 참관 / 매장 라운드 1개 이상 추가
- [ ] 마일스톤이 SaaS 식 "첫 PR 제출" / "첫 코드 리뷰" → 시즌 산출물 단위("첫 컨셉 보드 발표", "키 아이템 단독 디자인")로 교체
- [ ] 직무명이 영문(`Designer`, `Marketing Manager`) → 한국 패션 표준(디자이너, 마케팅 실장)으로 교체
- [ ] 리소스에 SaaS 도구만 (Jira, Linear, Confluence) → 한국 패션 표준(노션, 카페24, 무신사 파트너센터, ERP)으로 보강
- [ ] 입사일이 시즌 사이클과 무관한 어색한 시점 가정 → 입사 시점에 따라 마일스톤 합류 시즌 정합

## K-패션 특화 검수 (선택)

- [ ] 1주차 견학 공장이 K-패션 자연 — 대구 인견 / 부산 데님 / 합천 OEM / 안양 봉제 / 동대문 종합시장
- [ ] 회의 참관 항목이 시즌 사이클 정합 — 컨셉 보드 / 1차 품평회 / 2차 품평회 / 발주 회의 / 룩북 촬영 미팅
- [ ] 리소스에 무신사 파트너센터 / 29CM 파트너 / 카페24 등 K-패션 채널 도구 포함
- [ ] 브랜드 컬처 한 줄이 K-패션 자연 — 와키윌리(캐릭터 IP 팬덤) / 마뗑킴(SNS 친근 톤) / 아더에러(글로벌 신비감) / 마르디(셀럽 친화) / 무신사 스탠다드(한국적 핏)
- [ ] 1:1 일정에 직속 디렉터 + 대표 1회 포함 (한국 패션기업 일반적 신입 1주차 표준)
- [ ] 매장 라운드가 1주차 또는 2~4주차 일정에 포함 (디자이너 / MD / VMD 신입 표준)
