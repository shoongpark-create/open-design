# K-패션 랜딩 페이지 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 헤더 워드마크 + 4~5개 내비 링크가 존재. 모바일 800px 폭 이하에서 자연스럽게 스택
- [ ] 히어로 슬로건이 **18~24자 이내**. 영문 권장. 한국어 직역 금지 (`Bloom Quietly`는 그대로, `꽃피움 27SS`로 옮기지 않음)
- [ ] 히어로에 **1차 CTA + 2차 CTA** 정확히 1개씩 (예: `사전예약 시작` / `LOOKBOOK 보기 →`)
- [ ] 시그니처 아이템 **정확히 3개** (5개·6개 금지 — 시각 강도 분산됨)
- [ ] 각 시그니처 아이템에 번호(`01·`) + 영문 라벨(`HOODIE`) + 아이템명 + 한 줄 설명 + 가격 표기 (`₩148,000`)
- [ ] 소셜프루프 매거진은 **영문 워드마크 그대로** (`VOGUE KOREA`, `W KOREA`, `DAZED KOREA`) — `보그 코리아` 같은 직역 금지
- [ ] 회원 등급 또는 컬렉션 가격 3개 셀. 가운데(GOLD 또는 중간 등급)에 `featured` 클래스로 `RECOMMENDED` 뱃지
- [ ] 클로징 CTA가 액센트 풀폭 밴드 + 카운트다운 (`D-28` 또는 발매 일자) + 메인 CTA 버튼
- [ ] **액센트 컬러 사용 ≤ 3회** (히어로 1차 CTA + 회원 등급 추천 + 클로징 CTA). 4회 이상 금지
- [ ] 외부 이미지 URL 없음 (CDN, /tmp, base64 모두 금지). `.item-img` 같은 플레이스홀더 클래스 사용
- [ ] 가격 표기 `₩` 또는 `원` 중 일관성 있게 통일. `$` 표기 금지 (글로벌 자사몰 아닌 한)

## P1 — 강력 권장

- [ ] 디스플레이 폰트 1개만 `--font-display`에 바인딩. 디스플레이 폰트 여러 개 섞지 말 것
- [ ] 시그니처 아이템 카피가 **포엣코어 톤** — 기능 직설(`늘어나는 코튼`)이 아니라 감각·계절감 (`정원의 잔향이 머무는`)
- [ ] CTA가 **행동 동사**. `더보기`·`자세히` 금지. `사전예약 시작`, `BUY NOW`, `LOOKBOOK 보기` 우선
- [ ] 회원 등급명 영문 통일 (`SILVER / GOLD / PLATINUM` 또는 `WELCOME / REGULAR / VIP`)
- [ ] 모바일 800px 폭에서 `feature-grid`와 `tiers`가 단일 컬럼으로 스택
- [ ] 가격에 mono 폰트 (`.price` 또는 `.num` 클래스)
- [ ] 히어로 eyebrow가 `SPRING 27 · PRE-ORDER` 같은 mono 영문 대문자 + ` · ` 구분자

## P2 — 다듬기

- [ ] 시즌 코드 표기 일관성 (`27SS`, `27FW`)
- [ ] 헤더 내비 영문 라벨(`COLLECTION · LOOKBOOK · STORE`)이 mono + uppercase + letter-spacing
- [ ] 푸터에 사업자 정보 1줄 (`개인정보처리방침 · 이용약관 · CS · INSTAGRAM`)
- [ ] 액센트 컬러가 시즌 키 컬러와 정합성 (예: 와키윌리 SS = `#c96442` 톤)
- [ ] 클로징 CTA 배경 위 흰 텍스트 대비비 충족 (`color: #fff` + `opacity: 0.85` 본문)

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 페이지를 한 페이지에 두 메시지 섞은 것입니다 — 반드시 분리.

- [ ] 한 페이지에 `신규 런칭 + 콜라보 발매` 두 메시지가 동시에 들어있음 → 두 페이지로 분리
- [ ] 시그니처 아이템 4개 이상 → 3개로 줄이고 베스트만 노출
- [ ] CTA 버튼 3개 이상 → 1차 / 2차로 단순화 (`사전예약` + `LOOKBOOK`)
- [ ] 영문 슬로건을 한국어로 직역해서 별도 표기 (`Bloom 27SS / 꽃피움 27SS` 같은 형태) → 영문은 그대로, 한국어 데크는 별행 또는 생략

## K-패션 특화 검수 (선택)

- [ ] 카피·라벨에 K-패션 현장 영문 산업용어 사용 (`LOOKBOOK`, `DROP`, `COLLAB`, `PRE-ORDER`, `MEMBERS ONLY`, `LIMITED`)
- [ ] 가격은 한국 표준 표기 (`₩128,000` 또는 `128,000원`)
- [ ] 매거진 인용 영문 워드마크 (VOGUE KOREA, W KOREA, DAZED KOREA, ELLE KOREA, HARPER'S BAZAAR KR) — 4~6개
- [ ] 채널 라우팅 명시 — 자사몰(카페24) / 무신사 입점 / 29CM / 매장 중 어디로 보내는지 CTA URL placeholder 일관
- [ ] 시즌 사이클 정합성 — 콜라보 발매면 발매 1~2개월 전, 시즌 사전예약이면 S1 판기 3~4주 전 발행
