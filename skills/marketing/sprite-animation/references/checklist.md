# K-패션 스프라이트 애니메이션 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **JavaScript 절대 없음.** `<script>` 태그 0개. 모든 모션은 `@keyframes` only. 화면 녹화 → 인스타 릴스·틱톡 컨버전이 가능해야 합니다.
- [ ] **외부 이미지 URL 없음.** `<img src="https://...">` 또는 `background-image: url(https://...)` 절대 금지. 모든 스프라이트는 인라인 SVG, 모든 배경은 CSS 그라데이션/그레인.
- [ ] **최소 3개 독립 루핑 애니메이션 동시 가시.** 시드 기본 5개: `glitch`(year) + `bob`(sprite) + `kana-in`(한글) + `scroll-left`(ribbon) + `blink`(rec dot). 3개 이상이 항상 보여야 깊이감.
- [ ] **컬러 팔레트 = 크림 + 단일 액센트 + 잉크.** 시드의 `--paper` (크림) + `--accent` (브랜드 키컬러) + `--ink` (검정). 추가 컬러는 픽셀 아트 스프라이트 안에만 허용. UI 컬러로 4번째 색 도입 금지.
- [ ] **한글 키네틱 글자 수 1~3자.** 4자 이상은 모션 리듬이 깨짐. 시드 기본 2자(`윌리` `등장`).
- [ ] **시즌 코드 정확.** `27SS` / `27FW` (공백 없이, 영문 대문자). `27 SS`, `27ss` 금지.
- [ ] **16:9 풀-블리드 스테이지.** `aspect-ratio: 16/9`. 다른 종횡비 사용 시 인스타 릴스 9:16 재크롭 가능성 명시.
- [ ] **하단 리본 티커가 2배 복제로 무한 스크롤.** 시드 기본값 — 7개 항목 × 2 = 14개. `translateX(0 → -50%)`로 끊김 없는 루프. 1배만 두면 빈 화면 노출.
- [ ] **외곽 바디 다크 배경 (`#1a1816`).** 영상 프레임처럼 보이도록. 평평한 흰 배경 금지.
- [ ] **`data-od-id` 속성이 stage · topbar · year · sprite · kana · caption · ribbon에 있음** (OpenDesign 환경). 그 외는 `id` 속성 대체 가능.

## P1 — 강력 권장

- [ ] **시선 흐름이 큰 디스플레이 → 스프라이트 → 캡션 순서.** 좌하단 큰 시즌 코드(시선 진입) → 우상단 키네틱 한글 + 우중간 스프라이트 카드(중심 모티프) → 좌하단 캡션 본문(설명). 시선이 갈팡질팡하면 안 됨.
- [ ] **글리치 키프레임이 4초 중 1초만 깜빡.** 시드 기본값 (`88%, 100%`에서 invisible, `89~97%`에서 글리치). 글리치가 길어지면 산만함.
- [ ] **bobbing 진폭 ±8px.** 시드 기본값. 너무 크면 산만, 너무 작으면 안 보임.
- [ ] **REC/LIVE 깜빡임 글리프가 액센트 컬러.** `.rec::before`의 `background: var(--accent)`. 시드 기본값.
- [ ] **스프라이트 카드에 검정 그림자 (`box-shadow: 8px 8px 0 var(--ink)`).** 시드 기본값. 카드가 떠 있는 느낌 — 그림자 제거 금지.
- [ ] **캡션 본문이 mono + 이탤릭 세리프 헤더 혼용.** 시드 `.caption strong`이 이탤릭 세리프. 본문 mono. 두 톤이 공존해야 매거진 느낌.
- [ ] **상단 토프바 슬러그가 한글 + 영문 메타 혼용.** 예: `와키윌리 27SS · EP.01 · 윌리 캡슐 발매`. 한국어 키워드 + mono 영문 메타.
- [ ] **시즌 발매 일정 7개 항목** (리본). 5개 이하 = 빈약, 9개 이상 = 산만.

## P2 — 다듬기

- [ ] **코너 정렬 마크 4개 (L자).** 시드의 `.reg.tl/tr/bl/br`. 매거진 톤 미세 디테일. 제거하면 평범해 보임.
- [ ] **스테이지 페이퍼 그레인 (4px + 7px 듀얼 그리드).** 시드 기본값. 평평한 단색 페이퍼 금지.
- [ ] **스테이지 상하 그라데이션 (8% / 92%).** 시드의 `.stage::before` — 상하단에 미세한 그림자. 인쇄 페이퍼 톤.
- [ ] **스프라이트 카드 내부 검정 라인 2개** (`.sprite-card::before/after`). 시드 기본값. 트레이딩 카드 느낌.
- [ ] **`image-rendering: pixelated`** 스프라이트 SVG에 적용. 픽셀 아트 톤 유지.
- [ ] **모바일 900w 이하에서 year 폰트 120px로 축소** (이미 시드에 있음).

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 K-패션 스프라이트 모션이 아닙니다 — 반드시 수정.

- [ ] `<script>` 또는 JS 사용 → CSS `@keyframes`만으로 재구현
- [ ] `<img src="...">` 또는 외부 폰트 외 외부 리소스 사용 → 인라인 SVG/CSS로 교체
- [ ] 한글 키네틱 4자 이상 (예: `오늘도 즐겁게`) → 1~3자로 줄임 (`즐거움`, `오늘`)
- [ ] 시즌 코드 표기 오류 (`27 SS`, `2027SS`, `27ss`) → `27SS` 표준 표기
- [ ] 컬러가 4가지 이상 사용 (액센트 2개) → 크림 + 단일 액센트 + 잉크 3가지로 제한
- [ ] 모든 모션이 같은 속도 또는 1개 모션만 보임 → 3개 이상 다른 속도
- [ ] 외곽 바디가 흰 배경 → 다크 (`#1a1816`)로 변경
- [ ] 리본이 1배만 (스크롤 시 빈 화면 노출) → 2배 복제
- [ ] 발매 일정 표기 `2027.05.10` 같은 풀 연도 → `05.10` 또는 `MAY 10` 축약

## K-패션 특화 검수 (선택)

- [ ] 캡션 카피에 K-패션 영문 산업용어 (`LOOKBOOK`, `DROP`, `사전예약`, `회원`, `캡슐`, `한정`)
- [ ] 발매 일정에 K-패션 채널 명시 (`자사몰`, `무신사 단독`, `성수 팝업`, `회원 사전예약`)
- [ ] 스프라이트 모티프가 브랜드 시그니처 (와키윌리 = 캐릭터, 키르시 = 체리, 마뗑킴 = 워드마크/추상)
- [ ] 시즌 키 컬러가 액센트와 일치 (와키윌리 SS = `#e98425` 오렌지, 키르시 SS = `#d92b1c` 체리 레드)
- [ ] 한글 키네틱이 브랜드 톤 일치 — 마뗑킴 = 미니멀 단어 (`쿨`, `매일`), 와키윌리 = 위트 (`윌리`, `등장`)
- [ ] 채널 R&R 정합 — 마케팅실(컨셉) · 그래픽팀(비주얼) · 영상 프로덕션(확장 영상) · 이커머스팀(채널 적재)
- [ ] LOOP 시간이 화면 녹화에 적합 — 22s 리본 + 4s 글리치 → 24~30초 정도 녹화로 1회 풀루프 캡처 가능
