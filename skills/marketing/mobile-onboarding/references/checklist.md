# K-패션 앱 온보딩 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **3개 폰 프레임이 모두 진짜 폰처럼 보임.** Dynamic Island(`.island`) 보임, 상태 바 SVG 아이콘(시그널/와이파이/배터리)이 텍스트 아닌 글리프, 홈 인디케이터가 화면 마지막 요소. 시드가 모두 그려두었으니 마크업 삭제 금지.
- [ ] **각 폰에 페이지 인디케이터 `<div class="pager">`가 있고, 활성 위치가 폰 1·2·3에 맞게 다름** (1·2·3 순서대로 `active`).
- [ ] **각 폰에 primary CTA가 있음.** 폰 1 = `시작하기`, 폰 2 = `계속`, 폰 3 = 사인인 옵션 or `다음` CTA. CTA 누락 금지.
- [ ] **사인인 옵션은 카카오 첫 번째.** Apple/Google 첫 번째 금지 (한국 표준 위반). 순서는 카카오 → Apple → 네이버 → 이메일.
- [ ] **사인인 라벨은 한국 표준 표기**: `카카오로 시작하기`, `Apple로 계속하기`, `네이버로 계속하기`. `Continue with Apple` 같은 영문 원문 금지.
- [ ] **외부 이미지 URL 없음.** 모든 히어로 일러스트는 인라인 SVG. CDN 이미지·base64 모두 금지.
- [ ] **본문 텍스트 ≥ 14px.** 시드의 `--fs-body`가 15px 기본. 13px는 terms/note에만 허용.
- [ ] **탭 타깃 ≥ 44px.** CTA 48px, 사인인 옵션 48px 이미 강제. 작게 만들지 마세요.
- [ ] **액센트 컬러 사용 ≤ 3회 per 폰.** 보통: pager active + CTA(또는 chip on) + 강조 1개. 4회 이상 금지.
- [ ] **`data-od-id` 속성이 stage · phones · phone-1/2/3 · 주요 섹션에 있음** (OpenDesign 환경). 그 외는 `id` 속성 대체 가능.
- [ ] **디스플레이 폰트 1개 + 본문 sans 1개.** 헤드라인은 `var(--font-display)` 사용. 세 번째 폰트 도입 금지(mono만 숫자에서 예외).
- [ ] **시즌 코드 표기 정확.** `27SS` / `27FW`, 영문 대문자, 공백 없이.

## P1 — 강력 권장

- [ ] **스테이지 캡션이 브랜드 + 시즌 + 화면 종류를 명명** (`마뗑킴 · 27SS · 자사몰 앱 온보딩`). 시드의 `.stage-caption` 슬롯 사용.
- [ ] **카피가 브랜드 톤 일치**: 마뗑킴 = 미니멀 (`쿨하게, 매일.`), 마르디 = 로맨틱 (`오늘도 사랑스럽게.`), 아더에러 = 컨셉추얼 (`왜곡된 일상, 새로운 시선.`), 와키윌리 = 위트 (`오늘도 즐겁게.`).
- [ ] **헤드라인 18~24자 이내.** 한 줄 또는 두 줄로 끊김. 너무 길면 행 들숨이 흐트러집니다.
- [ ] **상태 바 시간은 `9:41`** (Apple 표준). 시드 기본값.
- [ ] **3번째 스크린이 한 가지 메인 액션.** 사인인 + 스타일 진단 + 알림 권한을 한 화면에 섞지 마세요.
- [ ] **carousel `건너뛰기`/`도움말` 위치 일관성.** 1·2번 스크린: `건너뛰기`. 3번 스크린: `도움말` 또는 생략.
- [ ] **숫자에 mono 폰트** — STEP 표시(`STEP 2 OF 4`), 시간(`9:41`), 통화(`₩ 원`). 시드의 `.num` 클래스.
- [ ] **회원 사전예약 강조.** 2번 스크린 밸류프롭에서 `회원만의 사전예약` 또는 `사전예약 24시간 우선 오픈` 같은 K-패션 산업 어휘 사용.

## P2 — 다듬기

- [ ] **스테이지 배경에 미세한 라디얼 그라데이션** (이미 시드에 있음). 평평한 단색 배경 금지.
- [ ] **카카오 글리프 노란색 (`#fee500`) + 검은 K 글자.** 한국 표준. 다른 색 금지.
- [ ] **푸시·알림톡 카피가 친근한 호칭** (`회원님`, `~ 시작합니다`).
- [ ] **terms 라인이 10~13px**, `var(--muted)` 컬러, 한국어 (`이용약관`, `개인정보처리방침`).
- [ ] **카피에 영문 산업용어 자연 혼용** — `LOOKBOOK`, `사전예약`, `VIP`, `MEMBERS ONLY`, `SS/FW` 우선.
- [ ] **시즌 KV 일러스트가 브랜드 시그니처 모티프** (와키윌리 = 캐릭터, 마르디 = 꽃, 키르시 = 체리, 아더에러 = 추상 그래픽).

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 K-패션 온보딩이 아닙니다 — 반드시 수정.

- [ ] 사인인 첫 번째가 카카오가 아님 → 카카오를 첫 번째로 이동
- [ ] CTA 라벨이 `더보기` / `자세히` → 행동 동사로 (`시작하기`, `계속`, `다음`, `사전예약 시작`)
- [ ] 가격 표기 `$` (글로벌 자사몰 화면이 아닌데) → `₩` 또는 `원`
- [ ] 카피 안에 데이팅·게임 클리셰(`Match`, `Spark`, `Quest`, `용사`) → K-패션 톤으로 교체
- [ ] 3개 폰이 모두 같은 화면 (스플래시 3번) → 1·2·3 각각 다른 목적(스플래시 / 밸류프롭 / 사인인 또는 진단)
- [ ] 페이지 인디케이터가 모든 폰에 같은 위치 active → 1·2·3 순서대로 다르게

## K-패션 특화 검수 (선택)

- [ ] 사인인 4개 옵션이 한국 표준 순서(카카오 → Apple → 네이버 → 이메일)
- [ ] 카카오 글리프 노란색 + 검은 글자 (`#fee500` + `#3c1e1e`)
- [ ] 카피·라벨에 K-패션 영문 산업용어 (`LOOKBOOK`, `DROP`, `VIP`, `MEMBERS ONLY`, `사전예약`)
- [ ] 시즌 KV가 시즌 컬러 토큰과 정합성 (액센트 = 시즌 키 컬러)
- [ ] 브랜드 톤 일치 (미니멀 / 로맨틱 / 컨셉추얼 / 위트 — SKILL.md 참고)
