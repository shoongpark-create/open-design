# K-패션 와이어프레임 v0.1 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수 ("이것은 스케치다" 신호)

- [ ] **그래프 페이퍼 배경** — `body` 또는 `.canvas`에 24px 그리드 (`repeating-linear-gradient`) 또는 도트 그리드 적용
- [ ] **마커·연필 톤** — 본문 폰트가 손글씨 (`var(--hand)` = Patrick Hand / Caveat / Architects Daughter). 시스템 폴백은 italic serif
- [ ] **WIREFRAME v0.1 핀** — 페이지 헤더에 대시 보더 + 살짝 회전된 핀 (`.pin`) 표시. v0.1 / v0.2 같은 단계 명시
- [ ] **활성 시안 1개만 형광펜 스와이프** — `.tab.active::before`로 노란 형광펜. 나머지 탭은 비활성
- [ ] **3~5개 탭 시안** — 사이안 A/B/C/D 또는 정보형/매거진형/룩북형/스토리형. 1개 시안만 있는 와이어프레임 금지
- [ ] **사이드바 메뉴** — 페이지 종류에 맞는 K-패션 메뉴 (상세페이지: 상품 정보 / 사이즈 가이드 / 소재 / 모델 / 리뷰 / Q&A / 배송)
- [ ] **KPI 4개 타일** — K-패션 등록 (`발매가`, `정상판매율 타겟`, `LOT`, `컬러웨이`, `사이즈 풀`, `발매일`). SaaS 등록 (`MAU`, `ARPU`, `Churn`) 금지
- [ ] **스티커 메모 1~2개** — 디자이너 메모 톤 (`여백 +20%`, `MD 검토 후`, `B안 선호`, `p.1 / 5`). 영문 일반 텍스트(`Note here`) 금지
- [ ] **URL 행 한국 K-패션 도메인** — `musinsa.com`, `29cm.co.kr`, `matinkim.com`, `mardimercredi.com`, `wackywilly.kr`. 영문 placeholder(`example.com`) 금지
- [ ] **픽셀 정확하지 않음** — 픽셀 정확하다면 와이어프레임이 아닙니다. `web-prototype` 스킬 사용
- [ ] **외부 이미지 URL 없음** — 모든 시각 요소가 CSS + 인라인 SVG로 처리

## P1 — 강력 권장 (디자이너 메모 톤)

- [ ] **살짝 회전 흩뿌리기** — KPI 타일·탭·캔버스에 `transform: rotate(-0.7deg ~ 1.2deg)` 같은 미세 회전 (그리드 깨기)
- [ ] **샤피 펜 그림자** — `.canvas`에 `box-shadow: 6px 8px 0 -4px rgba(...)` 같은 오프셋 그림자
- [ ] **해치 채움 막대 차트** — `<pattern>` SVG로 해치 패턴 적용 (단순 색 채움 금지)
- [ ] **손그림 폴리라인 차트** — `stroke-linecap: round`, `stroke-linejoin: round`로 손그림 느낌
- [ ] **스티커 메모 테이프** — `.sticky .tape` 가짜 테이프 자국 + 메모 컬러 (yellow / pink / blue 3종 활용)
- [ ] **탭 라벨 영문 + 한국어 혼용** — `01 · A · 정보형 (무신사 기본)`, `02 · B · 매거진형 (29CM 톤)`
- [ ] **페이지 헤더 meta** mono 폰트 + 영문 대문자 + tracking (`DATE 2026-05-15 · DEVICE DESKTOP 1440 · STAGE v0.1 · FIDELITY LOW`)
- [ ] **NEXT STEP 박스** — 액센트 보더 + `v0.5 시안 리뷰 → v1.0 픽셀 디자인` 다음 단계 명시
- [ ] **디자인 메모 자리표시** — `이벤트` 또는 `디자인 메모 (직근 3건)` 박스로 placeholder 표시
- [ ] **인사·이름·가격 토글** — 메인 영역 상단에 인사 + 시즌 라벨 + KEY ITEM 이름 + 정가/프리오더/VIP가 토글

## P2 — 다듬기

- [ ] 시즌 코드 일관 (`27SS`, `27FW`)
- [ ] 차트 라벨이 mono 폰트 + 영문 대문자 (`CHART · 정상판매율 추이`)
- [ ] KPI value에 액센트 컬러 1~2개 (`color: var(--accent)` 또는 `color: var(--ink)`)
- [ ] KPI small 라벨에 손글씨 폰트 + pencil 컬러
- [ ] 모바일 1000px 폭 이하에서 사이드바 숨김, KPI 2열, 스티커 메모 숨김
- [ ] 푸터 또는 NEXT STEP 박스에 다음 단계 (`v0.5 리뷰`, `v1.0 web-prototype`) 명시
- [ ] 디스플레이 폰트가 변형에 맞게 1개 선택 (정보형 = serif, 콜라보 = play, 스트리트 = street)

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 와이어프레임이 아닙니다 — 픽셀 디자인으로 넘어간 것입니다.

- [ ] 본문 폰트가 시스템 산세리프 (`-apple-system`, `Pretendard`) → 손글씨 폰트(`Patrick Hand`, `Caveat`)로 교체
- [ ] 컬러가 픽셀 디자인 톤 (`#1c1b1a`, `#fafaf9`) → 종이/잉크 톤(`var(--paper)`, `var(--ink)`, `var(--pencil)`)
- [ ] 모든 요소가 정렬 정확 → 살짝 회전(`transform: rotate(±0.6deg)`) 흩뿌리기
- [ ] 차트가 실제 데이터 시각화 → 손그림 SVG 자리표시자
- [ ] 모델컷·룩북 이미지가 실제 이미지 → `[이미지 자리]` placeholder 박스
- [ ] WIREFRAME v0.1 핀 없음 → 페이지 헤더에 반드시 핀 표시
- [ ] 스티커 메모가 영문 일반 텍스트 (`Lorem ipsum`, `Note here`) → 한국 디자이너 메모 톤 (`여백 +20%`, `MD 검토 후`)
