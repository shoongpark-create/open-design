# K-패션 운영 대시보드 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 좌측 사이드바가 sticky이며, 6~10개 네비 링크 + 1~2개 group 라벨 + 액티브 상태 1개 보유
- [ ] 상단바에 시즌 크럼(`WACKYWILLY · 27SS · S1 판기`) + 페이지 제목 + 우측 기간 필터 + Primary CTA
- [ ] KPI 카드 **정확히 4개** (3개·5개 금지). 각 카드에 라벨 + 큰 숫자 + Δ 화살표(▲/▼) + 비교 단위(YoY/MoM/WoW/QoQ/pp)
- [ ] 기본 KPI 4종 권장 — 정상판매율(정판율) · 재고자산회전율 · 시즌 GMV · AOV. 변경 시 K-패션 표준 KPI만 사용
- [ ] **정판율 60~85% 범위** (95% 같은 비현실 금지). 재고자산회전율 카테고리 3~20회
- [ ] 모든 차트는 **인라인 SVG**. 외부 이미지 URL, base64, CDN 차트 라이브러리(Chart.js·D3) 금지
- [ ] 채널 표기 한국 표준 — 무신사 / 29CM / W컨셉 / 자사몰 / 한섬몰 / 지그재그 / SSF샵 (`Musinsa`·영문 직역 금지)
- [ ] 통화 단위는 원 / 만원 / 억 (USD 금지). 가격은 `₩98,400` 또는 `98,400원` 일관
- [ ] 액센트 컬러 사용 ≤ 4회 (사이드바 액티브 + 차트 강조 + Primary CTA + 콜아웃 1개)
- [ ] 모든 색상은 `:root` 토큰에서 옴 — 임의 hex 금지

## P1 — 강력 권장

- [ ] 폰트는 본문 `Pretendard Variable`, 디스플레이는 `--font-display-report` (운영 대시보드 톤)
- [ ] 숫자 셀은 모노 폰트 + tabular-nums (`td.num`, `.kpi .value`)
- [ ] BTA 도넛이 있다면 분포 정합 — Basic 40~50% / Trend 30~40% / Accent 10~20%
- [ ] 카테고리 표가 있다면 5~8행. UNI / WOMEN / ACC 구분 명시
- [ ] QR / SPOT 결정 콜아웃은 `<b>SKU 코드 + 발주 수량 + 데드라인 + 데시전 오너</b>` 4종 모두 포함
- [ ] KPI Δ가 모두 같은 비교 단위가 아니어야 함 — YoY · MoM · WoW 섞어쓰기 자연스럽게
- [ ] 정판율은 `pp` (percentage point) 표기. GMV는 `%` 표기

## P2 — 다듬기

- [ ] 사이드바 네비에 SKU 카운트, BTA 비중 같은 사이드 카운트 칩 1~3개
- [ ] 상단바 sticky 시 메인 영역 스크롤 자연
- [ ] 모바일 1020px 폭에서 사이드바가 상단으로 떨어지고 KPI 2x2 그리드로 폴백
- [ ] 차트 캡션·범례는 한국어 명사구 종결 — "일별 GMV · 5/1 ~ 6/14"
- [ ] 시즌 코드 표기 일관성 (`27SS`, `26FW`, `S1 판기`, `S1 D+18`)
- [ ] 액센트 컬러가 시즌 키 컬러와 정합 (와키윌리 SS = `#c96442` 톤, 마뗑킴 SS = 페일 핑크)

## 하드 룰 위반 점검 (anti-pattern)

- [ ] KPI 카드 5개 이상 → 4개로 줄이기. 영업기획 시야가 분산됨
- [ ] 차트에 외부 라이브러리 import → 인라인 SVG로 변경
- [ ] 영업 데이터에 USD 금액 → 원 단위로 변환
- [ ] 정판율 95%+ 또는 50% 이하 → 한국 K-패션 평균 60~85% 범위로 보정
- [ ] 무신사·29CM 영문 직역(`Musinsa`, `29CM Co.`) → 한국 표기 그대로

## K-패션 특화 검수 (선택)

- [ ] 사이드바 메뉴 라벨에 K-패션 운영 용어 — 정판율 / BTA 비중 / QR 후보 / 무신사 베스트 / 알림톡
- [ ] 카테고리 분류가 K-영캐주얼 표준 (UNI · WOMEN · ACC · KIDS) — `Men · Women`만 쓰지 말 것
- [ ] 시즌 판기 표기 S1 (5-6월) · S2 (7월) · S3 (8월) · S4 (9월) 정합
- [ ] BTA 태그 색상 — Basic 그레이 톤 · Trend 블루/그린 톤 · Accent 액센트(브랜드 키 컬러)
