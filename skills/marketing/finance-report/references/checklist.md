# K-패션 시즌 결산 보고서 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 마스트헤드에 브랜드 + 시즌·판기 코드 + 발행일 + Confidential 배지 + 부서(영업기획) 5종 모두 보유
- [ ] 시즌 요약 lede 1문단이 **정량 수치 2~3개** 포함 (매출 12.4억, 정판율 78.4%, BTA 비중)
- [ ] KPI 카드 **정확히 4개** — 기본 권장 시즌 GMV · 정상판매율 · 재고자산회전율 · AOV
- [ ] 각 KPI에 라벨 + 큰 숫자 + Δ + 비교 단위(YoY/QoQ/MoM/pp) + 서브 텍스트(베이스라인) 5종 보유
- [ ] **정판율 60~85% 범위** (95% 같은 비현실 금지). 재고자산회전율 시즌 환산 4~20회
- [ ] 매출 추이 차트는 **인라인 SVG**. 외부 라이브러리 금지
- [ ] 비용 분해는 사입원가 + 마케팅비 + 물류비 + 인건비 + 시스템/임차료 **5종 모두** 포함. 매출 대비 % 표기
- [ ] P&L 표에 매출 / 사입원가 / 매출총이익 / 마진율 / 마케팅 / 물류 / 인건비 / 시스템 / 영업이익 / 영업이익률 10행 모두 보유
- [ ] P&L 비교 컬럼 — 현재 판기 + 전년 동기 + YoY + 전판기 + QoQ 5개 컬럼 (또는 동등 구조)
- [ ] TOP SKU 표 5~10행. SKU 코드 + 카테고리 + BTA + 판매수량 + GMV + 정판율 6컬럼
- [ ] 아웃룩 문단에 다음 판기·시즌 전망 + 리스크 1개 명시
- [ ] 사인오프에 작성자(영업기획팀 + 이름) + 검토(MD실) + 승인(대표) 3종 + 발행일

## P1 — 강력 권장

- [ ] 통화 단위 원 / 만원 / 억 (USD 금지)
- [ ] 변동 표기 ▲/▼ + % 또는 pp (정판율·마진율은 pp, GMV·SKU 매출은 %)
- [ ] 폰트: 본문 Pretendard, 디스플레이는 `--font-display-report` (운영·재무 톤)
- [ ] 표 숫자는 모노 폰트 + tabular-nums + 우측 정렬 (`td.num`)
- [ ] 액센트 컬러 최대 3번 — 마스트헤드 Confidential 배지 + 차트 강조 + 아웃룩 좌측 보더
- [ ] 모든 색상은 `:root` 토큰. 임의 hex 금지
- [ ] BTA 태그 색상 일관 — Basic 그레이 / Trend 블루 / Accent 액센트
- [ ] 영업이익률(OPM) 30~45% 범위 (한국 영캐주얼 평균)
- [ ] 비용 분해 % 합산이 ~62% 정도 (영업이익률 38% 가정 시)

## P2 — 다듬기

- [ ] 마스트헤드 하단 2px solid border (분리 강조)
- [ ] P&L 표의 매출총이익·영업이익 행은 `tr.subtotal` 또는 `tr.total` 클래스로 강조
- [ ] 차트에 점선 비교 라인 (전년 동기 또는 plan) 1개 추가
- [ ] 모바일 820px 폭에서 KPI 2x2 + 비용바 1단으로 폴백
- [ ] 시즌 코드 일관 (`27SS S1 판기`, `26SS S1`, `26FW`)
- [ ] 작성자 시그니처에 부서 + 직급 + 이메일 (선택)

## 하드 룰 위반 점검 (anti-pattern)

- [ ] 통화에 `$` 또는 `USD` → 원/만원/억으로 변환
- [ ] KPI 카드 3개 또는 5개 → 정확히 4개로
- [ ] 정판율 95%+ → 한국 평균 60~85% 범위로 보정
- [ ] P&L 표에 매출총이익 행 누락 → "매출 - COGS = 매출총이익" 행 추가
- [ ] 아웃룩이 단순 매출 전망만 → 리스크 1개 명시
- [ ] 사인오프 누락 → 작성자 + 검토 + 승인 3종 필수
- [ ] 차트에 Chart.js·D3 import → 인라인 SVG로 변환

## K-패션 특화 검수 (선택)

- [ ] 시즌·판기 표기 한국 표준 (`27SS S1 판기`, `26FW S3 판기`)
- [ ] 회계 용어 한국 표준 — 매출 / 사입원가 / 매출총이익 / 영업이익 / 마진율 / 사입가율
- [ ] BTA 비중 lede에 언급 — Basic 43% · Trend 35% · Accent 22% 같은 분포
- [ ] 무신사 베스트 TOP 30 진입 SKU 개수 언급 (시즌 KPI 외 보조 지표)
- [ ] R&R — 영업기획팀(작성) + MD실(검토) + 대표(승인) 흐름 명시
- [ ] 아웃룩에 다음 시즌·판기 IMC 캠페인명 1개 언급 (BLOOM, COZY HOLIDAY 등)
