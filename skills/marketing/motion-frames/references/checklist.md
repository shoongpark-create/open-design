# K-패션 시즌 키비주얼 모션 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수 하드 게이트, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **JavaScript 절대 없음.** `<script>` 태그 0개. 모든 모션은 `@keyframes` only. HyperFrames/Lottie/After Effects가 결정론적으로 캡처할 수 있어야 합니다.
- [ ] **외부 이미지 URL 없음.** `<img src="https://...">` 또는 `background-image: url(https://...)` 절대 금지. 모든 비주얼 인라인 SVG + CSS 그라데이션.
- [ ] **최소 3개 레이어가 다른 속도로 회전.** 시드 기본값: r1(60s) + r2(90s 역방향) + r3(180s) + r4(36s) + focal(38s 역방향). 모두 같은 속도면 깊이감이 사라집니다.
- [ ] **액센트 컬러는 헤드라인 이탤릭 단어 1회만.** 시드의 `<span class="accent">` 한 군데. focal-dot의 pulse 액센트는 의도된 단일 보조 사용 — 그 외 액센트 0회.
- [ ] **핵심 요소가 가운데 70% 영역 안.** 헤드라인, 포컬 마크, 링은 모두 화면 중앙 70% 안. 9:16 재크롭(인스타 릴스 60% 폭) 시 잘리지 않아야 함.
- [ ] **모션을 frame 0에서 멈춰도 포스터로 읽힘.** 정지컷에서 헤드라인 + 코너 크롬 + 포컬 마크 + 라벨이 모두 일독 가능. 정적 포스터로 동작해야 모션 캡처도 안정.
- [ ] **루프 길이 8~16s 자연스러움.** 시드 권장 12s. 4s 미만 또는 30s 이상은 어색.
- [ ] **헤드라인이 포엣코어 톤.** 직설 카피(`Buy Now!`, `사전예약 시작!`) 금지. 시적·관조적(`Bloom Quietly. 봄, 천천히 피어나다.`).
- [ ] **코너 크롬에 mono 폰트 적용.** 시드의 `.chrome`, `.meta-tl`, `.issue`는 `var(--font-mono)`. 일반 sans로 바꾸지 마세요.
- [ ] **`data-od-id` 속성이 stage · composition · focal · ring-labels · headline에 있음** (OpenDesign 환경). 그 외는 `id` 속성 대체 가능.
- [ ] **풀블리드 16:9.** `<main>`이 `width: 100vw; height: 100vh`. 모바일 폭에서도 종횡비 유지. 카드형 (마진 보더) 레이아웃 금지.

## P1 — 강력 권장

- [ ] **링 라벨 키워드 5~8개.** 4개 이하 = 빈 느낌, 9개 이상 = 산만. 시드 기본 8개.
- [ ] **링 라벨 키워드가 시즌 컨셉을 한 번에 보여줌.** 시즌 코드(27SS) + 영문 슬로건 단어(BLOOM, Quietly) + 한국어(봄) + 컬러/소재(ivory, sage, Linen). 무관한 키워드 금지.
- [ ] **헤드라인이 영문/국문 혼용.** 예: `Bloom Quietly. 봄, 천천히 피어나다.` 영문 슬로건은 그대로 두고 한국어 데크 별행. 영문 직역(`꽃피움 조용히`) 금지.
- [ ] **코너 크롬에 시즌 코드 + 데이트라인.** 좌상단: 스튜디오 + 날짜(`MATIN KIM STUDIO — APR 10 · 2027`). 우상단: 시즌·이슈(`27SS · BLOOM`). 좌하단: LOOP 정보(`LOOP · 12s · CSS`). 우하단: 활용 채널(`REELS / IG / SHOP`).
- [ ] **포컬 마크가 브랜드 시그니처 모티프와 일치.** 마뗑킴 = 추상 globe, 마르디 = 꽃, 와키윌리 = 캐릭터, 키르시 = 체리. 임의의 모티프 금지.
- [ ] **디스플레이 폰트 1개 + mono 1개.** 헤드라인 + 링 라벨은 같은 디스플레이 폰트. 코너 크롬 + 데이트라인은 같은 mono. 세 번째 폰트 도입 금지.
- [ ] **type-in 키프레임이 헤드라인에만 적용.** 다른 요소에 type-in 적용하면 모션 리듬이 흐트러집니다.
- [ ] **focal-dot pulse가 단일 액센트 강조 포인트.** 다른 요소에 pulse 추가하면 강조가 분산.

## P2 — 다듬기

- [ ] **스테이지에 미세한 점 그리드** (이미 시드에 있음, 28px 간격). 평평한 단색 배경 금지.
- [ ] **`baseline` 라인이 헤드라인 하단에 보임** (1px, opacity 0.25). 매거진 톤 미세 디테일.
- [ ] **링 r3가 dashed** (`border-style: dashed`). 시드 기본값. solid로 바꾸지 마세요 — 깊이감이 줄어듭니다.
- [ ] **포컬 마크 그라데이션이 부드러움** (radialGradient). 평평한 fill 금지.
- [ ] **링 라벨 폰트 사이즈 12px**, 이탤릭. 시드 기본값. 너무 크면 회전 시 산만함.
- [ ] **반응형 — 900w 이하에서 헤드라인 28px로 축소** (이미 시드에 있음).

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 모션 포스터가 아닙니다 — 반드시 수정.

- [ ] `<script>` 또는 `onclick=` 같은 JS 사용 → CSS `@keyframes`만으로 재구현
- [ ] `<img src="...">` 또는 외부 폰트 외 외부 리소스 사용 → 인라인 SVG/CSS로 교체
- [ ] 액센트 컬러가 2개 이상 요소에 사용 → 헤드라인 이탤릭 단어 1개만
- [ ] 모든 레이어가 같은 속도로 회전 → 60s/90s/180s/36s 등 다른 속도로
- [ ] 헤드라인이 직설 카피 (`Buy Now`, `사전예약 시작`) → 포엣코어 톤으로 교체
- [ ] 풀블리드 아닌 카드형 (마진 보더 있음) → `100vw × 100vh` 풀스크린
- [ ] 링 라벨 9개 이상 → 5~8개로 줄임
- [ ] 핵심 요소가 가장자리에 (`bottom: 0`, `left: 0`) → 가운데 70% 영역으로 이동
- [ ] 영문 슬로건을 한국어로 직역해 별 표기 (`Bloom 27SS / 꽃피움 27SS`) → 영문 그대로 + 한국어 데크 별행

## K-패션 특화 검수 (선택)

- [ ] 헤드라인이 영문 + 한국어 혼용 (`Bloom Quietly. 봄, 천천히 피어나다.`)
- [ ] 링 라벨에 시즌 코드 1개 (`27SS`, `27FW` — 공백 없이)
- [ ] 시즌 키 컬러가 `--accent` 토큰과 일치 (와키윌리 SS = 오렌지, 마뗑킴 SS = 구릿빛)
- [ ] 코너 크롬에 활용 채널 표기 (`REELS / IG / SHOP` 또는 `자사몰 · 무신사 · 인스타`)
- [ ] LOOP 정보 명시 (`LOOP · 12s · CSS`) — HyperFrames 캡처 시간 가이드
- [ ] 16:9와 9:16 재크롭 모두 동작 — 인스타 릴스 60% 폭 시뮬레이션 시 헤드라인 안 잘림
