# K-패션 매거진 포스터 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] **헤드라인이 페이지를 지배.** 디스플레이 세리프, 오버사이즈 (clamp 56~124px), 2~3줄. 가장 무거운 시각 요소
- [ ] **취소선 정확히 1단어** (`<span class="strike">`) — 부정·반전의 단어
- [ ] **이탤릭 액센트 정확히 1단어** (`<span class="accent-word">`) — 핵심 주장 단어. 액센트 컬러 + 이탤릭
- [ ] 헤드라인 전체에 취소선 2개 이상 또는 이탤릭 액센트 2개 이상 없음 (시각 강도 분산됨)
- [ ] 데이트라인 + 상단 룰 존재. mono 타입라이터 폰트 (Courier Prime, IBM Plex Mono)
- [ ] 데크(subhead)가 헤드라인 직후, 이탤릭 세리프 + `—` 대시 구분자 + 마지막에 액센트 콜아웃 (`— 그래서, 입는다`)
- [ ] **6개 번호 섹션 모두 채워짐.** 각 셀 = 아이브로우(`01 · COLOR`) + 서브 헤드라인 + 본문 + 콜아웃 인용
- [ ] 본문이 **진짜 의견·서술**. `lorem ipsum`, 플레이스홀더 카피 금지
- [ ] **액센트 컬러는 헤드라인 액센트 단어 + 액센트 룰 + 6개 콜아웃 박스 외 추가 사용 금지** (과한 그라데이션·다중 컬러 금지)
- [ ] 페이지 배경이 크림 페이퍼 톤(`#f3eee2` 또는 등가) + 미세한 노이즈 도트
- [ ] 외부 이미지 URL 없음 (CDN, /tmp, base64 모두 금지) — 시각 요소는 룰·도트·콜아웃만으로
- [ ] 데이트라인 / 아이브로우 / 풋터가 모두 mono 타입라이터 톤

## P1 — 강력 권장

- [ ] 1280~1440px 폭에서 의도된 매거진 1면처럼 보임 (인쇄 포스터 비율)
- [ ] 본문 그리드 3단 (2×3 또는 3×2). 1024px 이하 2단, 640px 이하 1단으로 리플로우
- [ ] 풋터 밴드에 `BRAND VOICE` 또는 `FOUNDING` 같은 플레이트 + 한 줄 마무리 카피
- [ ] 데이트라인 일자는 ISO 또는 한국어 일자 (`2027.04.10 · 토요일` 형식)
- [ ] 6개 섹션 아이브로우 형식 일관 (`01 · COLOR`, `02 · SILHOUETTE` — mono + ` · ` 구분자)
- [ ] 콜아웃 인용문이 한 문장. `"`로 감싸지고 mono + 이탤릭 톤
- [ ] 헤드라인의 취소선/이탤릭 단어 선택이 의도적 — 부정 단어를 취소선, 핵심 주장을 이탤릭

## P2 — 다듬기

- [ ] 인쇄 포스터로 출력해도 무리 없는 톤 (인쇄 미디어 쿼리 포함)
- [ ] 본문 한국어 종결이 명사구 또는 단정형 (`~다.`, `~인다.`) — 신문 사설 호흡
- [ ] 데크 이탤릭 단어 (`<em>그래서, 입는다</em>`)가 헤드라인 액센트 단어와 톤 일치
- [ ] 페이퍼 노이즈 도트가 너무 강하지 않음 (저투명도 ~0.04)
- [ ] 페이지 여백이 인쇄용 A2/A3 안전 영역을 의식한 패딩

## 헤드라인 패턴 사례 (포엣코어 + 취소선·이탤릭)

올바른 헤드라인 패턴 예시:

- 마뗑킴 27SS: `우리는 봄을 ~~외치지 않는다.~~ *입는다.*`
- 마르디 26FW: `Le hiver n'est pas une saison. C'est ~~une attente.~~ *Une fête.*`
- 와키윌리 출범: `즐거움은 ~~선택~~ 사항이 아니다. *첫 약속이다.*`
- 아더에러 27SS: `Spring is ~~a noun.~~ It is *a verb.*`

부정 단어를 취소선, 핵심 주장을 이탤릭으로 대비.

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 포스터가 광고 배너처럼 보입니다.

- [ ] 취소선 0개 또는 2개 이상 → 정확히 1개로
- [ ] 이탤릭 액센트 0개 또는 2개 이상 → 정확히 1개로
- [ ] 6개 섹션 중 빈 셀이 있음 → 모두 채우거나 4개·5개로 줄임 (단, 4·5단 그리드 재계산 필요)
- [ ] 헤드라인이 광고 카피 톤 (`최대 50% 할인!`) → 매니페스토 톤으로 (`우리는 ~을 외치지 않는다`)
- [ ] 외부 이미지 사용 → 룰·도트·콜아웃으로만 시각 표현
- [ ] 액센트 컬러 3가지 이상 사용 → 단일 액센트로
- [ ] 페이지 배경이 흰색 → 크림 페이퍼 톤으로 (`#f3eee2`, `#ede8dc`)

## K-패션 특화 검수 (선택)

- [ ] 영문 산업용어 그대로 (`SS`, `FW`, `LOOKBOOK`, `DROP`, `CAMPAIGN`, `COLLAB`, `POP-UP`, `MANIFESTO`)
- [ ] 시즌 코드 일관성 (`27SS`, `BLOOM 27SS`)
- [ ] 본문 톤이 신문 사설처럼 차분 — 과한 `!`, `??`, 이모지 금지
- [ ] 풋터 닫는 카피가 시그니처 한 문장 (`봄, 천천히 피어나다. — 매트 김.`)
- [ ] 인스타그램 1:1·4:5 크롭 시 헤드라인 + 1~2 섹션만 보이도록 시각 우선순위 설계
- [ ] 카카오톡 친구톡 이미지로 헤드라인 크롭 시 가독성 유지 (헤드라인 단독으로도 의미가 살아남는지)

## 매거진 포스터의 5대 사용처

이 포스터 1장이 다음 5개 자리에 모두 어울리는지 확인:

1. **A2/A3 인쇄 포스터** — 매장·팝업 게재
2. **자사몰 매거진 1면** — 디지털 매거진 톱 비주얼
3. **인스타그램 첫 장 캐러셀** — 1:1 또는 4:5 크롭
4. **카카오톡 채널 친구톡 이미지** — 헤드라인 크롭본
5. **PR 이메일 첨부** — 매거진사·인플루언서 발송

특히 인스타그램 1:1 크롭 시 헤드라인이 단독으로도 의미가 살아남아야 합니다.
