# K-패션 이메일 마케팅 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 가운데 정렬 단일 컬럼 (600~680px). 마스트헤드 → 히어로 → 헤드라인 → 본문 → CTA → 스펙 → 푸터 순서
- [ ] **CTA 1개만 존재**. 본문 안에 두 번째 CTA(예: `LOOKBOOK 보기 →`)를 넣지 말 것 (텍스트 링크는 OK)
- [ ] 헤드라인이 **포엣코어 톤** — 기능 직설(`늘어나는 코튼`) ❌, 감각 서술(`구름의 감촉`) ⭕
- [ ] 헤드라인 락업에 액센트 단어 1개 (`skew(-6deg)` 또는 이탤릭) 적용. 액센트 단어가 너무 많으면 안 됨
- [ ] **액센트 컬러 최대 2회** (eyebrow + CTA 또는 헤드라인 액센트 단어 + CTA)
- [ ] **480px 폭 미디어 쿼리** 존재. 모바일에서 헤드라인 한 단계 축소, specs 단일 컬럼
- [ ] 외부 이미지 URL 없음 (CDN, /tmp, base64 모두 금지) — 인라인 SVG + 그라데이션으로 처리
- [ ] 영문 산업용어 그대로 유지 (`SKU`, `DROP`, `LOOKBOOK`, `MEMBERS ONLY`, `PRE-ORDER`)
- [ ] **카카오톡 알림톡 카피 2~3안**이 본문 끝 `.alimtalk` 블록 또는 별도 마크다운으로 함께 제안됨
- [ ] 발송 대상 (회원 전체 / VIP / 사전예약 신청자)이 푸터 또는 HTML 주석에 명시
- [ ] 푸터에 **수신거부 + 브라우저에서 보기** 링크 존재. 사업자 정보(사업자등록번호·통신판매업) 1줄

## P1 — 강력 권장

- [ ] 이메일이 위에서 아래로 **8~10초 안에 읽힘** (스크롤 1회 이내)
- [ ] 마스트헤드에 워드마크 + 우측 짧은 내비(`SHOP · LOOKBOOK · MEMBERS`) + 헤어라인 보더
- [ ] 히어로 블록에 stamp(좌상단) + colorway 태그(좌하단) + drop 정보(우하단) 3개 메타 슬롯 모두 채워짐
- [ ] 스펙 그리드 2×2 또는 2×3. K-패션 표준 항목:
  - `3 COLORS` / `컬러웨이 3종`
  - `XS — XL` / `사이즈 5단계`
  - `₩108,800` / `회원가 · 정상가 −15%`
  - `LINEN 100%` / `Cool Linen 가공 · MADE IN KOREA`
- [ ] 가격에 mono 폰트 + `₩` 한국 표준 표기. `$` 표기 금지
- [ ] 알림톡 카피 호칭이 친근하지만 과하지 않은 표현 (`매트 김 회원님`, `매트 김 VIP 회원님`)
- [ ] 알림톡 카피에 `${shop_link}` 같은 변수 placeholder가 정확히 표기됨 (실제 발송 시 카페24·비즈센터에서 치환)

## P2 — 다듬기

- [ ] 페이지 배경이 페이퍼톤 틴트(`#f3eee2` 톤). 본문 박스는 흰색으로 떠 있는 메타포
- [ ] 헤드라인 자모 간격(`letter-spacing: -0.015em`) 적용. 한국어 디스플레이 폰트에서 자모 간격 너무 헐겁지 않음
- [ ] eyebrow가 mono + 영문 대문자 + ` · ` 구분자 (`NEW DROP · LINEN SHIRT · SPRING 27`)
- [ ] 푸터 배경에 액센트 4% 틴트로 본문과 자연스럽게 분리
- [ ] 알림톡 카피 이모지 0~2개 절제. `짱`, `대박` 같은 과한 감탄 금지

## 알림톡 카피 검수 (200자 이내)

알림톡 발송 카피는 다음 조건을 충족해야 합니다.

- [ ] **80~200자** 사이 (카카오 비즈센터 알림톡 표준 길이)
- [ ] 호칭 1번 (`${고객명}님` 또는 `매트 김 회원님`)
- [ ] 발매 일자 + 키 아이템 한 줄
- [ ] CTA URL placeholder (`${shop_link}`, `${vip_link}` 등)
- [ ] 이모지 1~2개 또는 0개
- [ ] `짱`, `대박`, `❤️❤️❤️` 같은 과한 감탄 금지

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 이메일이 "마케팅 폭탄"처럼 보입니다 — 반드시 재작성.

- [ ] CTA 버튼 2개 이상 → 1개로 단순화
- [ ] 액센트 컬러 3회 이상 사용 → 2회로 축소
- [ ] 헤드라인이 풀 문장 길이 (40자 이상) → 명사구 또는 2~3줄로 분리
- [ ] 영문 슬로건을 한국어 직역해서 동시 표기 (`Bloom 27SS / 꽃피움 27SS`) → 영문은 그대로, 한국어 데크는 별행
- [ ] 외부 CDN 이미지 사용 (`https://cdn.brand.com/...`) → 인라인 SVG + 그라데이션으로 대체

## K-패션 특화 검수 (선택)

- [ ] 한국 K-패션 표준 폰트 (Pretendard Variable) 본문 적용
- [ ] 시즌 코드 표기 일관성 (`27SS`, `27FW S2`)
- [ ] 매거진/인플루언서 인용은 영문 워드마크 유지 (직역 금지)
- [ ] 채널 라우팅 명확 — CTA URL이 자사몰·무신사·29CM 중 어디로 보내는지 코멘트로 명시
- [ ] 발송 대상 분기 명확 (회원 전체 vs VIP vs 사전예약 신청자)
