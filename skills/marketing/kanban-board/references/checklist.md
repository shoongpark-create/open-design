# K-패션 시즌 진척 보드 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수, **P1**은 강력 권장, **P2**는 다듬기.

## P0 — 통과 필수

- [ ] 상단바에 시즌 크럼(`WACKYWILLY · 27SS · 진척 보드`) + 페이지 제목 + 펄스 칩(`S1 D-42 · LOCK 75%`) 보유
- [ ] 컬럼 수가 리듬에 맞음 — 리듬 A 6단 / B 5단 / C 4단 / D 5단
- [ ] **6단 보드의 경우 LOCK이 4번째 컬럼**, 그 다음 발주·생산, 마지막 입고·판매 — 순서 변경 금지
- [ ] 모든 컬럼에 카드 보유 (빈 컬럼 금지). 컬럼당 3~6장
- [ ] 전체 카드 수 18~26장. 30장 초과 금지 (시야 분산)
- [ ] 각 카드에 SKU 코드 + 룩 이름 + 디자이너 + BTA 태그 (B/T/A) 4종 모두 보유
- [ ] SKU 코드 패턴 일관 — `WW-27SS-XXX`, `MM-26FW-XXX` (브랜드 코드-시즌-카테고리)
- [ ] BTA 분포 자연스럽게 — Basic 40~50% / Trend 30~40% / Accent 10~20%. Basic이 0%이거나 80%+면 비현실적
- [ ] 사이드바에 **LOCK 진행률 + Top 디자이너 + 블로커 콜아웃** 3개 블록 모두 보유
- [ ] 블로커 콜아웃에 구체적 사유(원단 미입고 / MOQ 미달 / 발주 지연) + 데드라인 + 담당
- [ ] 모든 색상은 `:root` 토큰 — 임의 hex 금지

## P1 — 강력 권장

- [ ] 디자이너 이니셜은 한글 두 글자 — 지훈 / 수민 / 은지 / 하늘 / 윤서 (영문 이니셜만 쓰면 한국 패션기업 톤 부족)
- [ ] BTA 색상 — Basic 그레이 / Trend 블루 / Accent 액센트(브랜드 키 컬러)
- [ ] LOCK 컬럼 카드는 `.locked` 클래스 + `LOCK · 1,800장` 같은 발주 수량 명시
- [ ] 블락된 카드는 `.blocked` 클래스 + 빨간 dashed border
- [ ] 카드 진행률 바(.progress)는 컬럼 단계에 비례 — 1단 20~30%, 4단 LOCK 100%
- [ ] LOCK 비중이 펄스 칩 비율과 일치 (예: 칩 LOCK 75% → 24/32 LOCK 표기)
- [ ] 무신사 베스트·자사몰 TOP 같은 K-패션 채널 성과 메타 1~2장 카드에 표시

## P2 — 다듬기

- [ ] 필터바 칩이 BTA 분포(`Basic 43% · Trend 35% · Accent 22%`)와 정합
- [ ] 사이드바 sticky 시 보드 영역과 스크롤 분리
- [ ] 모바일 1100px 폭에서 컬럼이 3단으로 폴백, 720px 이하 1단
- [ ] 시즌 코드 일관 (`27SS`, `S1 판기`, `5-6월`)
- [ ] 카드 폰트 크기·여백·border-radius 일관성

## 하드 룰 위반 점검 (anti-pattern)

- [ ] LOCK 컬럼이 마지막에 위치 → LOCK은 4번째여야 함 (발주 전)
- [ ] 카드가 30장 초과 → 18~26장으로 압축. 시각 강도 분산됨
- [ ] BTA 분포에서 Basic 0% 또는 Accent 50%+ → 한국 K-영캐주얼 평균 분포로 보정
- [ ] 영문 디자이너 이니셜만 사용(`MJ`, `SH`) → 한글 두 글자 우선
- [ ] 블로커 콜아웃에 구체적 데드라인·담당 누락 → 추가
- [ ] SKU 코드가 카드마다 패턴 다름 → 한 패턴으로 통일

## K-패션 특화 검수 (선택)

- [ ] 시즌 표기 한국 표준 — `27SS`, `26FW`, `S1 판기`, `S2 판기`
- [ ] 카테고리 분류 — UNI · WOMEN · ACC · KIDS (영문)
- [ ] 캐리오버(전 시즌 재발매) SKU 1~2개 카드에 표시
- [ ] QR / SPOT 후보 표시 — 입고·판매 컬럼에서 `무신사 BEST 12 · QR 후보` 같은 메타
- [ ] 디자이너·MD R&R — 컨셉~1차 샘플은 디자이너, LOCK은 MD 실장, 발주는 MD 책임
