# K-패션 발주서·거래명세서 자체 검수 체크리스트

산출물 출력 직전에 한 항목씩 직접 확인하세요. **P0**는 통과 필수(법적 효력에 영향), **P1**은 강력 권장(실무 미스 차단), **P2**는 다듬기.

## P0 — 통과 필수 (사업자 양식 / 법적 효력)

- [ ] **공급자 / 공급받는자 사업자등록번호** 양쪽 모두 `xxx-xx-xxxxx` 형식으로 표기
- [ ] **대표자 이름 + 사업장 주소 + 업태 + 종목** 양쪽 모두 채워짐 (한 곳이라도 누락 시 세금계산서 발행 불가)
- [ ] **공급가액(VAT 별도) + 부가세 10% + 합계금액** 3개 행이 합계 블록에 모두 표시
- [ ] **통화 단위 = 원 / 만원 / 억**. USD/$/€ 표기 절대 금지 (OEM 거래는 원화 표준)
- [ ] **결제 조건** 명시 — 한국 패션 OEM 표준 (`40% 선급 / 60% 입고 시`, `30/30/40`, `Net 30`) 중 하나
- [ ] **문서 번호** 형식 일관 (`PO-27SS-W001`, `STM-27SS-W001`, `PO-SPOT-27SS-W001-02`, `MSA-2027-A`)
- [ ] **LOT 번호 = LOT-{시즌}-{라인}-{차수}** 형식 (예: `LOT-27SS-W001`, `LOT-27SS-W001-SPOT-02`)
- [ ] **발행일 + 입고 예정일** 또는 **거래일 + 지급 마감일** 양 일자 모두 표기
- [ ] **사인 라인** — 자필 서명 + 직무 + 이름 + 소속 명시 (`김도하 · 생산실 PD, (주)와키윌리`)
- [ ] **숫자 정렬** — `td.num`과 `th.num`에 `text-align: right` + `font-variant-numeric: tabular-nums` 적용 (자리 어긋남 금지)

## P1 — 강력 권장 (K-패션 OEM 실무)

- [ ] **MOQ 명시** — `MOQ 200`, `MOQ 500` 같은 최소발주수량 명시 (참조 스트립 또는 라인 아이템 비고)
- [ ] **사입가율 명시** — `사입가율 28%`, `사입가율 30% (+2%p)` 같은 영캐주얼 표준 (25~35%) 범위
- [ ] **사이즈 어소트** — `S/M/L 어소트 2:3:2` 형식, 비율 명시 (S만 다 발주하지 않도록)
- [ ] **컬러웨이 코드** — `CW01 OAT`, `CW02 NAVY` 형식. 컬러 락 코드와 매칭
- [ ] **견본 컨퍼(CON) 일자 + 본생산 시작 일자** 약관에 명시
- [ ] **세금계산서 발행 방식** — `홈택스 전자세금계산서` 명시. 발행 시점(`선급 입금 후 익일`) 표기
- [ ] **입금 계좌** — 은행 + 계좌번호 + 예금주 + 입금 메모 (`PO-27SS-W001` 입금 메모로 매칭)
- [ ] **회계 시스템 호환** — 더존 / 케이뱅크 / 영림원 ERP에 그대로 등록할 수 있는 필드 셋
- [ ] **MSA 참조** — `MSA 2026.02.14 기준` 처럼 본계약 일자 인용 (양식 A·B·C)
- [ ] **OEM 공장 거점** — 한국 거점 (합천 / 진주 / 안양 / 안산 / 부천 / 시흥 등) 명시 (해외 OEM은 별도 환율/관세 약관 필요)

## P2 — 다듬기

- [ ] 시즌 코드 표기 일관 (`27SS`, `27FW`)
- [ ] 통화 표기 일관 (`72,000,000원` 또는 `72,700,000 KRW` — 한 양식에 1형식만)
- [ ] `font-variant-numeric: tabular-nums` 미적용 시 수량 자리수가 어긋남
- [ ] 인쇄용 `@media print` 적용 — 배경 제거, 단일 페이지에 들어가도록
- [ ] 모바일 720px 폭 이하에서 `parties`·`pay`·`totals`가 1열로 스택
- [ ] 합계 그랜드 라인에 배경(검정) + 흰 텍스트로 시각 강조
- [ ] 사인 라인의 자필 서명이 `Brush Script MT` 또는 `Snell Roundhand` cursive 폰트
- [ ] 푸터에 OEM 공장 연락처 (위챗·카카오) 1줄 (옵션)

## 하드 룰 위반 점검 (anti-pattern)

다음 중 하나라도 해당하면 발주서가 *법적 효력*에 흠집이 갑니다 — 반드시 보강.

- [ ] 사업자등록번호 한 쪽만 표기 → 양쪽 모두 표기
- [ ] 부가세 표기 없음 또는 `VAT 포함` 단일 표기 → `공급가액 + 부가세 10% + 합계` 3행 분리
- [ ] 결제 조건 모호 (`나중에 지급`, `협의 후`) → 표준 약관 (`40/60`, `Net 30`) 명시
- [ ] LOT 번호 없음 → SKU와 동등하게 LOT 번호 필수
- [ ] 자필 사인 라인 없음 → 도장 자리라도 표시 (`(인)`)
- [ ] USD/$/€ 표기 → 원화로 환산하고 환율 명시 (단, 한국 내 OEM은 원화만)
- [ ] 한 발주서에 동일 SKU 중복 라인 → 컬러웨이가 다르면 별도 라인, 같으면 합산

## K-패션 OEM 특화 검수 (선택)

- [ ] 클레임 약관 — `합격 미달 시 별도 처리`, `불량률 3% 이내 허용` 같은 K-패션 표준 약관
- [ ] 견본 발주(견본가) vs 본생산 발주 구분 — 견본가는 본생산 대비 +30~50% 정상
- [ ] SPOT P/O 사입가 인상 — 1차 대비 +5~10% 표준
- [ ] 외상 매입 / 어음 / 카드 결제 옵션 명시 (회계 시스템 호환)
- [ ] 보험 / 운송 책임 (CIF / FOB) — 국내 OEM은 보통 `매수인 부담`
- [ ] 부서 R&R 사인 — 1억 미만 = 생산실 PD + MD 실장, 1억+ = CFO 컨펌 라인 추가
