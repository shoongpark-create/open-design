## 1. 시즌 운영 사이클

### 판기 구조 (S1~S4)

한국 패션 기업은 1년을 SS(봄/여름)과 FW(가을/겨울)로 나누고, **소비 패턴의 계절성에 신속 대응하기 위해 4개 판기로 세분화**한다. 기획은 실제 판매 시점에서 **최소 6~9개월 전부터 역산 기획(Backward Planning)**으로 시작한다.

| 판기 | 시기 | 상품 |
|---|---|---|
| **S1 — Early Spring** | 1~2월 | 간절기 아우터, 가디건, 얇은 니트 (FW 시즌오프와 병행하며 봄 무드 선제 도입) |
| **S2 — Summer** | 3~6월 | 티셔츠, 셔츠, 반바지 등. **연중 가장 긴 판매 기간, 전체 물량 비중 최대** |
| **S3 — Pre-Fall** | 7~8월 | 가을 선발매 상품 (하반기 트렌드 테스트 베드) |
| **S4 — Winter** | 9~12월 | 코트, 패딩 등 헤비 아우터. **객단가가 높아 연 매출의 40~50% 견인** |

### 상품 분류 (BTA) + 캐리오버/QR/SPOT

| 분류 | 운영 방식 | 목적 |
|---|---|---|
| **Basic** | 매 시즌 반복 출시하는 **캐리오버(Carry-over)** | 다량 생산으로 사입가율 낮춰 마진 극대화. **브랜드 캐시카우** |
| **Trend** | 적은 수량으로 시장 반응 살핀 후, 반응 좋으면 **2~3주 내 QR(Quick Response) 추가 발주** | 시즌 유행 흡수, 리오더 매출 핵심 |
| **Accent** | 룩북 메인 착장/화제성용 소량 생산 (고가, 실험적) | 이미지 제고, 브랜드 톤 강화 |
| **SPOT** | 기획 단계에 없던 급부상 트렌드를 시즌 중 급기획·생산 | 시장 변화 탄력 대응 |

### 브랜드 사례 (실제 데이터)

- **마르디 메크르디 (Mardi Mercredi)**: 시그니처 IP인 **'플라워 마르디' 그래픽 패턴 고정 + 매 시즌 컬러/원단 변주** 전략. **재고자산회전율 20회 / 업계 평균(3~4회)의 약 5배**. 고효율 캐리오버 운영의 대표 사례.
- **마뗑킴 (Matin Kim)**: 온라인 팬덤 기반 **드롭(Drop) 전략** — 특정 시각 신제품 기습 공개 → 매진 유도. 대표가 직접 SNS 소통, 밈/질문 기능 활용한 친근한 톤. 인스타그램은 다이내믹·날것 vs 룩북은 텍스트 최소화·쿨한 무드.
- **무신사 스탠다드**: 플랫폼 내 수백만 건 검색·구매·후기 데이터 기반 수요 예측. **베이직 아이템 집중 + 연 900만 장 이상 대량 생산** → 가성비/품질 확보.

### 부서별 R&R

| 부서 | 역할 (시즌 사이클 관점) |
|---|---|
| **MD실 (상품기획실)** | 시즌 기획 총괄. 타깃 고객·생산 스타일/수량·목표 원가·판매가 산출. 정상판매율·재고 회전율 책임. **주간/월간 리뷰로 QR·SPOT 최종 결정** |
| **디자인실** | 무드/컬러/소재 스토리 + 작업지시서. 시그니처 IP 구축 (예: 마르디 플라워 로고) |
| **생산실** | 디자인실 샘플 → 대량 생산 연결. 협력 공장(벤더) 선정, 원·부자재 수급, **사양회의로 단가 협상**, 납기/QC 관리 |
| **영업기획실** | 자사몰·입점 플랫폼·오프라인 백화점 등 **채널 배분 결정**. 채널별 판매 속도/매장 효율 모니터링, 물동량 조율 |
| **마케팅실** | IMC 캘린더 기반. 룩북 촬영, SNS 운영, 인플루언서 협업, 팝업 기획. 온·오프라인 트래픽 유도 |

### CRM 마케팅 (카카오톡 채널)

**자동화 시나리오 마케팅** — 고객 구매 여정 단계마다:
1. 신규 유입 → 웰컴 쿠폰
2. 장바구니 이탈 → 리마인드 메시지
3. 첫 구매 후 → 리뷰 작성 유도
4. 쿠폰 소멸 예정 → 소멸 임박 알림

**메시지 톤매너 핵심:**
- **개인화**: "OO님, 장바구니에 담아두신 원피스 재고가 3개 남았어요"
- **긴급성/희소성**: 시크릿 쿠폰, 한정 수량, 마감 시한
- 짧고 친근. 이모지 1~2개

### 매거진형 화보·룩북 연출법

**기존 → 현재의 변화:**
- 백색 누끼컷 → **아이보리·콘크리트·우드 등 텍스처 있는 배경**
- 강한 그림자 → **소프트 라이트(Soft light)** — 질감/깊이감 살림
- 꽉 찬 프레임 → **넉넉한 여백(Negative Space)**
- 정형화된 포즈 → **무심한 표정, 걷는·움직이는 찰나의 순간**

**상세페이지 구조 (4단):**
1. **히어로 이미지** — 시즌 콘셉트 압도적 표현
2. **브랜드 스토리** — 제작 배경/디자이너 의도 문학적 서술
3. **에디토리얼 컷** — 일상 라이프스타일 제안 (착장)
4. **디테일 뷰** — 직조감·부자재 극단 클로즈업

### 한국형 카피라이팅 — "포엣코어(Poetcore)"

**핵심 트렌드:** 기능 직설 설명 ❌ → **시처럼 감각 서술** ⭕

**Before (기능 설명):**
> "신축성 좋은 코튼 소재"

**After (포엣코어):**
> "구름의 감촉을 닮아 부드럽게 몸을 감싸는 여유로운 실루엣"

**카피 톤 핵심 4요소:**
1. **문학적 서술** — 감각·정체성·라이프스타일 자극
2. **영문/국문 혼용** — 세련미·이국적 무드
3. **절제된 여백** — Whitespace로 프리미엄 인상
4. **운율** — 반복 구조·두운으로 리듬감

### 품평회 (Sample Review)

기획안이 프로토타입 샘플로 구현됐을 때 **상업성·완성도 평가 + 최종 생산 결정**의 가장 중요한 관문.

**복종별 진행 방식:**

| 복종 | 방식 |
|---|---|
| **여성복** | **전문 피팅 모델 활용 패션쇼 형식**. 디자인 실장이 디자인 포인트·실루엣 설명 → 참석자(MD·영업·매장 매니저)가 품평 시트에 점수/의견. 조명·코디·시즌 조형물 적극 활용 |
| **캐주얼·스트릿·남성복** | **행거 진열 + 참석자 직접 만지고 피팅**. 매장 매니저가 소비자 입장에서 꼼꼼히 평가 (실무적) |

**OK / NG 판단 기준 (디자인 심미성만이 아님):**
1. **목표 원가 준수 여부** — 원가·판매가 배수(사입가율) 기준 초과 시 NG 또는 사양회의로 디테일 수정
2. **매장 디스플레이 효과 + 코디 적합성** — 단일 아이템 매력 + **다른 아이템과 크로스 코디 적합성** + 매장 컬렉션 톤앤매너 적합성
