# Marketing 31개 스킬 K-패션 재해석 가이드

> 각 스킬의 **원래 용도**, **K-패션 컨텍스트 재해석**, **변환 작업량**, **예시 카피 방향**을 정리.
> 사용자 합의: 31개 모두 K-패션 컨텍스트화. 동떨어진 3개도 재해석.

## 분류 요약

| 분류 | 스킬 수 | 작업 시간 추정 |
|---|---|---|
| 🟢 가까움 (영어→한국어 + K-패션 카피 교체) | 13개 | 스킬당 30~60분 |
| 🟡 중간 (의미 일부 전환 + K-패션 사례 보강) | 15개 | 스킬당 60~120분 |
| 🔴 멈 (전면 재해석) | 3개 | 스킬당 120~240분 |

---

## 🟢 가까움 — 13개 (영어→한국어 + K-패션 사례)

### 1. `blog-post` (long-form 에디토리얼)
- **원 용도**: 마스트헤드, 히어로, 본문, 풀쿼트, 관련 글
- **K-패션 재해석**: 브랜드 매거진 컬럼, 스타일링 에세이, 시즌 컨셉 스토리, 디자이너 인터뷰
- **예시 컨텍스트**: "마뗑킴 27SS 컨셉 비하인드", "마르디 메크르디의 꽃이 만들어지기까지", "와키윌리 디자이너 노트"
- **톤 변경**: 서양 에디토리얼 → 한국 패션 매거진 (W Korea, Dazed Korea 톤)

### 2. `magazine-poster` (신문 스타일 포스터)
- **원 용도**: 뉴스프린트 종이톤, 데이트라인, 오버사이즈 세리프, 6개 번호 섹션
- **K-패션 재해석**: 시즌 캠페인 포스터, 팝업 안내, 브랜드 매니페스토
- **예시 컨텍스트**: "27SS 시즌 메니페스토", "코엑스 팝업 안내", "브랜드 출범 선언"

### 3. `social-carousel` (3-카드 인스타그램 캐러셀)
- **원 용도**: 1080×1080 시네마틱 3장, 헤드라인이 시리즈로 이어짐
- **K-패션 재해석**: 신상 발매 캐러셀, 시즌 컨셉 3장, 룩 시리즈
- **예시 카피**: "온워즈." → "투 더 넥스트 원." → "루킹 어헤드." 같은 서양식 시리즈 → "시작" → "이어서" → "오늘도" 같은 한국적 캐러셀 또는 영문 혼용 ("Quiet. / Steady. / Now.")

### 4. `motion-frames` (모션 디자인 키 프레임)
- **원 용도**: 회전 타입 링, 애니메이션 글로브, 타이머, 패럴랙스 라벨
- **K-패션 재해석**: 시즌 키비주얼 모션, 캠페인 영상 포스터, 브랜드 인트로
- **예시 컨텍스트**: "27SS BLOOM", "마뗑킴 신상 티저", "팝업스토어 인트로"

### 5. `email-marketing` (제품 론칭 이메일)
- **원 용도**: 마스트헤드, 히어로, 스큐 타이틀 락업, CTA, 스펙 그리드
- **K-패션 재해석**: 신상 발매 알림 이메일, 회원 사전예약 안내, 시즌 룩북 알림
- **예시 카피**: "EMBER FLARE / MAX-CUSHION TRAINER" 같은 스니커즈 톤 → "27SS 봄여름 신상", "마뗑킴 회원 사전예약 시작" 같은 K-패션 톤
- **추가 고려**: 카카오톡 알림톡 버전도 함께 (짧은 메시지 + 이미지 + CTA)

### 6. `digital-eguide` (디지털 e-가이드, 2 스프레드)
- **원 용도**: 표지 (제목, 저자, 목차) + 본문 스프레드 (레슨 본문, 풀쿼트, 단계 리스트)
- **K-패션 재해석**: 시즌 스타일링 가이드 PDF, 룩북 인터랙티브, VIP 회원 가이드
- **예시 컨텍스트**: "27SS Styling Guide", "Spring Layering 101", "데일리 핏 마스터하기"

### 7. `mobile-app` (의류 쇼핑 앱)
- **원 용도**: 픽셀 정확 iPhone 15 Pro 프레임 안 + 6가지 archetype
- **K-패션 재해석**: 무신사/29CM 스타일 의류 쇼핑 앱, 자사몰 앱, 멤버십 앱
- **예시 컨텍스트**: "27SS 신상 디스커버리", "VIP 멤버 라운지", "스타일 매칭"

### 8. `mobile-onboarding` (3-스크린 모바일 온보딩)
- **원 용도**: 스플래시 + 밸류프롭 + 사인인
- **K-패션 재해석**: 패션 앱 첫 화면, 회원가입 플로우, 스타일 취향 진단
- **예시 컨텍스트**: "마뗑킴 앱에 오신 것을 환영합니다", "당신의 스타일을 알려주세요", "회원 혜택 시작"

### 9. `dashboard` (운영/분석 대시보드)
- **원 용도**: KPI 카드, 차트, 테이블
- **K-패션 재해석**: 시즌 매출 대시보드, 채널별 매출, BTA 비중, 정상판매율
- **예시 컨텍스트**: "27SS S1 판기 매출", "채널별 GMV (무신사/29CM/자사몰)", "히어로 아이템 회전율"

### 10. `replit-deck` (개발자 톤 슬라이드 덱)
- **원 용도**: Replit 스타일 코딩 친화 덱
- **K-패션 재해석**: 시즌 기획 덱 (디자인실 내부 공유용), 라인업 리뷰 덱
- **예시 컨텍스트**: "27SS 디자인 기획 합본", "1차 품평회 리뷰"

### 11. `simple-deck` (심플 슬라이드 덱)
- **원 용도**: 미니멀 슬라이드 덱
- **K-패션 재해석**: 캠페인 보고 덱, 시즌 전략 발표, 콜라보 제안
- **예시 컨텍스트**: "27SS IMC 보고", "콜라보 제안서: WACKYWILLY x XX"

### 12. `finance-report` (분기/월 재무 보고서)
- **원 용도**: KPI 마스트헤드, 매출/번 차트, P&L, 하이라이트, 아웃룩
- **K-패션 재해석**: 시즌 매출 보고서, 월별/판기별 매출 리뷰
- **예시 컨텍스트**: "27SS S1 판기 매출 리포트", "26FW 시즌 결산", "Q1 정상판매율 리뷰"

### 13. `sprite-animation` (스프라이트 애니메이션)
- **원 용도**: CSS 키프레임 애니메이션 보드
- **K-패션 재해석**: 신상 발매 애니메이션, 키비주얼 모션, 로딩 페이지 인터랙션

## 🟡 중간 — 15개 (의미 일부 전환 + K-패션 사례)

### 14. `pricing-page` (가격 페이지)
- **원 용도**: 헤더, 플랜 티어, 기능 비교, FAQ
- **K-패션 재해석**: 멤버십 티어 페이지 (실버/골드/VIP), 정기배송 플랜, 프리오더 가격 페이지
- **예시 컨텍스트**: "VIP 멤버십 등급", "마뗑킴 베이직/플러스/프리미엄"

### 15. `web-prototype` (범용 데스크탑 웹 프로토타입)
- **원 용도**: 단일 self-contained HTML 랜딩/마케팅/SaaS 페이지
- **K-패션 재해석**: 자사몰 메인 페이지, 룩북 페이지, 팝업스토어 안내, 콜라보 페이지
- **예시 컨텍스트**: "27SS LOOKBOOK", "성수동 팝업", "콜라보 발매"

### 16. `wireframe-sketch` (수기 와이어프레임)
- **원 용도**: 그래프 페이퍼, 마커 톤, 손그림 + 스티커
- **K-패션 재해석**: 상세페이지 와이어프레임, 자사몰 페이지 스케치, 캠페인 페이지 초안
- **예시 컨텍스트**: "신상 상세페이지 와이어프레임", "27SS 룩북 페이지 스케치"

### 17. `kanban-board` (칸반 보드)
- **원 용도**: To do / In progress / Done
- **K-패션 재해석**: 시즌 진척 보드 (컨셉/샘플/품평/락업/생산/입고), 캠페인 진행 보드
- **예시 컨텍스트**: "27SS 시즌 진척", "27SS IMC 캠페인 칸반"

### 18. `team-okrs` (팀 OKR 트래커)
- **원 용도**: 분기 배너, 3개 Objective, KR 진행률, Owner
- **K-패션 재해석**: 시즌 OKR / KPI 트래커
- **예시 컨텍스트**: "27SS S/S 시즌 OKR", "디자인실 KPI", "MD실 정상판매율 목표"

### 19. `weekly-update` (위클리 업데이트)
- **원 용도**: 주간 보고
- **K-패션 재해석**: 시즌 위클리 매출 리포트, 위클리 인사이트 (영업기획 작성)
- **예시 컨텍스트**: "27SS W12 매출 리포트", "이번 주 무신사 베스트"

### 20. `meeting-notes` (회의 노트)
- **원 용도**: 미팅 노트 템플릿
- **K-패션 재해석**: 품평회 노트, 시즌 회의록, 콜라보 미팅 노트
- **예시 컨텍스트**: "27SS 1차 품평회 회의록", "27SS S1 발주 회의"

### 21. `pm-spec` (PM 스펙 / PRD)
- **원 용도**: 제품 요구사항 정의서
- **K-패션 재해석**: 신상품 기획서 (PRD → 상품 기획서), 콜라보 기획서, 팝업 기획서
- **예시 컨텍스트**: "27SS 키 아이템 기획서: 그래픽 티셔츠", "성수동 팝업 기획안"

### 22. `docs-page` (문서 페이지)
- **원 용도**: API/제품 문서 페이지
- **K-패션 재해석**: 브랜드 내부 위키, 디자인 시스템 문서, 운영 매뉴얼
- **예시 컨텍스트**: "마뗑킴 브랜드 가이드라인", "무신사 입점 매뉴얼"

### 23. `eng-runbook` (엔지니어링 런북)
- **원 용도**: 운영/장애 대응 런북
- **K-패션 재해석**: 발주/생산 운영 매뉴얼, 시즌 전환 체크리스트, 입고/QC 매뉴얼
- **예시 컨텍스트**: "27SS 발주 SOP", "시즌 입고 검수 체크리스트"

### 24. `hr-onboarding` (HR 온보딩)
- **원 용도**: 신입 사원 온보딩
- **K-패션 재해석**: 디자이너/MD 신입 온보딩 가이드, 브랜드 컬처 가이드
- **예시 컨텍스트**: "와키윌리 디자이너 온보딩", "MD 신입 1주차 가이드"

### 25. `invoice` (송장)
- **원 용도**: 인보이스
- **K-패션 재해석**: 발주서, 거래명세서, OEM 계약서
- **예시 컨텍스트**: "27SS 1차 발주서", "26FW 거래명세서"

### 26. `tweaks` (디자인 토큰 변경)
- **원 용도**: 디자인 토큰 마이크로-튜닝 도구
- **K-패션 재해석**: 시즌별 디자인 토큰 변경, 캠페인 토큰 오버라이드
- **예시 컨텍스트**: "27SS 컬러 팔레트 적용", "마뗑킴 콜라보 토큰 오버라이드"

### 27. `critique` (디자인 비평)
- **원 용도**: UI 리뷰
- **K-패션 재해석**: 룩북 리뷰, 상세페이지 검토, 콘텐츠 비평
- **예시 컨텍스트**: "27SS 룩북 1차 비평", "신상 상세페이지 검토"

### 28. `guizang-ppt` (Guizang 스타일 PPT)
- **원 용도**: 중국풍 디자인 PPT
- **K-패션 재해석**: 시즌 합본 덱 (영캐주얼 톤), 콜라보 제안서, IR 자료
- **예시 컨텍스트**: "27SS 시즌 합본", "글로벌 진출 IR"

## 🔴 멈 — 3개 (전면 재해석)

### 29. `saas-landing` → **K-패션 신규 브랜드 런칭 랜딩 페이지**
- **원 용도**: SaaS 단일 페이지 랜딩 (히어로, 기능, 소셜프루프, 가격, CTA)
- **K-패션 재해석**: 
  - **새 브랜드 런칭 랜딩** (브랜드 소개 + 컨셉 + 라인업 미리보기 + 사전예약 CTA)
  - 또는 **무신사 입점 페이지 톤** (브랜드 스토리 + 베스트셀러 + 룩북 + 신규회원 혜택)
  - 또는 **컬래버레이션 발매 페이지** (콜라보 스토리 + 컬렉션 + 발매 카운트다운 + 사전예약)
- **섹션 매핑**:
  - 히어로 → 키비주얼 + 브랜드 슬로건
  - 기능 → 시그니처 아이템 / 디자인 철학
  - 소셜프루프 → 인플루언서 워닝 / 매거진 인용
  - 가격 → 회원 등급 또는 콜라보 가격
  - CTA → 사전예약 / 회원가입 / 룩북 보기
- **예시 카피**: 
  - 서양: "Scale your team with AI" → 한국: "당신의 일상에 스며드는 스타일"
  - 서양: "Trusted by 10,000+ companies" → 한국: "VOGUE, W KOREA 추천 브랜드"
- **참고 브랜드**: 마뗑킴 자사몰, 마르디 메크르디 캠페인 페이지, 아더에러 콜라보 페이지

### 30. `dating-web` → **K-패션 멤버십 / VIP 매칭 / 스타일 추천 대시보드**
- **원 용도**: 매칭 대시보드 (sunday-paper 톤, 데이트 콘텍스트)
- **K-패션 재해석**:
  - **VIP 멤버 라운지 대시보드** (회원 등급 + 추천 스타일 + 매장 초대 + 시그니처 혜택)
  - 또는 **퍼스널 스타일 매칭 결과 페이지** (AI 스타일 진단 결과 + 추천 룩 + 매칭 아이템)
  - 또는 **인플루언서 매칭 대시보드** (브랜드와 인플루언서 매칭)
- **섹션 매핑**:
  - 프로필 카드 → 회원 프로필 (스타일 키워드, 좋아요 한 아이템)
  - 매칭 결과 → 추천 룩 카드
  - 메시지 → 스타일링 상담 (채널톡 연동)
- **예시 카피**:
  - 서양: "Find your perfect match" → 한국: "당신과 어울리는 스타일을 만나보세요"
