# 키 아이템 슬라이스 라이브러리

각 아이템 패밀리는 5 슬라이스 중 다른 서브셋을 자연스럽게 노출. *아이템*이 답하는 슬라이스를 선택, 예쁘게 보이는 슬라이스 선택 금지. 제너릭 5-슬라이스 스프레드는 AI-슬롭의 신호 — 실제 스튜디오 시트는 2~4 선택.

## 5 슬라이스

| 슬라이스 | 무엇을 보이는가 | 포함 시점 |
|---|---|---|
| **Color** | 동일 가먼트, 다중 컬러웨이, 행거 또는 플랫레이 | 다중 컬러 개발 아이템; 니트, 데님 셋업, 베이직에 필수 |
| **Detail** | 1 구성 요소 매크로 클로즈업 (커프스, 헴, 포켓, 드로코드, 스티칭, 지퍼 풀) | 시그니처 디테일 보유; 뉴 베이직, 이지 데님 셋업, 리이슈 실루엣에 필수 |
| **Pattern** | 스와치 스케일 패턴: 우븐(체크, 스트라이프, 도트), 프린트(카모, 플로럴), 구조(와플, 립) | 패턴이 스토리인 아이템 (체크 셔츠, 폴카 도트 시리즈, 카모, 러플/레이스) |
| **Fabric** | 핸드 + 드레이프 표시 스와치 클로즈업, 선택 패브릭 태그 오버레이 | 패브릭이 업그레이드인 아이템 (기능성 쿨링, Sorona, 데님 무게, 슬럽 저지) |
| **Artwork** | 그래픽 / 자수 / 패치 / 스티커 / 워드마크 스터디, 가먼트 영역 또는 플랫레이에 고립 | 아트워크가 가치인 아이템 (시그니처 그래픽 티, 빈티지 그래픽 티, 젤리 로고 락업) |

## 아이템 패밀리별 권장 컴포지션

| 아이템 패밀리 | 기본 슬라이스 | 왜 |
|---|---|---|
| 아우터 — 코튼 집업 점퍼 | Washing · Pattern · Artwork | 아우터 스토리 = *worn surface texture* — 워싱 변형, 플레이드 패턴, 자수 체스트 패치 |
| 아우터 — 윈드브레이커 / 나일론 | Color · Detail · Fabric | 기능이 가치 — 컬러, 드로코드/지퍼 디테일, 라이트 패브릭 |
| 톱 — 시그니처 그래픽 티 | Artwork · Fabric | 가치 = 그래픽 + 쿨링 패브릭 (Cool Cotton, Askin); 실루엣은 제너릭 |
| 톱 — 빈티지 그래픽 티 | Graphic · Fabric (Pigment Dyeing 패브릭 노트) | 페이드 컬러 + 슬럽 저지 + 레트로 그래픽 = 아이템 전체 |
| 톱 — 베이직 / 뉴 베이직 티 | Color · Detail · Fabric | 가치 = 핏 + 넥라인 + 저지 그레이드 |
| 니트 — 가디건, 스웨터, 베스트 | Color · Pattern · Detail · Fabric | 니트는 네 슬라이스 자연 분할 |
| 하의 — 이지 데님 셋업 | Color · Detail · Fabric | 컬러 라벨, 시그니처 스티칭/자수, 기능성 데님 (Coolmax, Linen-like) |
| 하의 — 스웻팬츠 / 쇼츠 | Color · Detail · Fabric | 위와 동일 |
| 셋업 — 데님라이크 스웻 셋업 | Color · Detail · Fabric (Washing은 Color 내 서브 노트) | 셋업은 컬러웨이 스토리 + 시그니처 디테일 필요 |
| 원피스 / 스커트 | Color · Detail · Pattern | 패턴이 자주 스토리 (폴카 도트, 플로럴, 레이스) |
| 햇 / 캡 | Color · Detail · Artwork | 캡 가치 = 컬러, 브림/스트랩 디테일, 자수 |
| 백 / 백팩 | Color · Detail · Pattern (또는 Artwork) | Detail = 스트랩, 지퍼, 링; 패턴은 해당 시 |
| 신발 (스니커즈, 샌들, 슬라이드) | Color · Detail · Fabric | 소재 어퍼 + 솔 디테일 |

## 믹스 *금지* 슬라이스

- **Color × Pattern** — 패턴이 컬러 변형 포함 시 시각 충돌. Pattern을 모노크롬으로 표시, Color는 Color 슬라이스에서 처리
- **Detail × Artwork** — 티에서 thumb 스케일에 동일하게 읽힘. 1개 선택
- **Pattern × Artwork** — 패턴 패브릭 위 자수 패치 아우터에서 — 시즌 히어로 어느 쪽인지 선택

## 슬라이스 명명 변형

일부 스튜디오는 로컬 슬라이스 이름 사용. 템플릿의 canonical 5에 매핑:

| 스튜디오 이름 | Canonical 슬라이스 |
|---|---|
| Washing / Wash | Color (Color 서브 축으로 처리) |
| Print | Pattern *또는* Artwork (반복 시 Pattern, 고립 시 Artwork) |
| Embroidery | Artwork |
| Trim | Detail |
| Hardware | Detail |
| Finish | Fabric *또는* Color (핸드 변경 시 Fabric, 컬러 변경 시 Color) |
| Material | Fabric |
| Knit structure | Pattern (립/케이블 가시 시) *또는* Fabric (핸드 시) |

## 한국 K-패션 키 아이템 시즌 시그니처 사례

- **마뗑킴 26SS '시그니처 미니백'**: Color · Detail (텍스트 로고 자카드) · Material (가죽 그레이드)
- **마르디 메크르디 26SS '플라워 마르디 카디건'**: Artwork (플라워 마르디) · Color · Detail (버튼)
- **아더에러 25FW '시그니처 코트'**: Color (블루 시그니처) · Detail (테트라이트 로고 라벨)
- **키르시 26SS '체리 후디'**: Artwork (체리 그래픽) · Color · Fabric (스웻 그레이드)
- **와키윌리 27SS '코튼 집업 점퍼'**: Washing · Pattern · Artwork (캐릭터 자수)
- **무신사 스탠다드 26SS '쿨 코튼 티'**: Color · Detail (네크라인) · Fabric (Cool Cotton 행택)
- **시야쥬 26SS '린넨 셔츠'**: Color · Fabric (린넨 핸드) · Detail (커프스·헴)
