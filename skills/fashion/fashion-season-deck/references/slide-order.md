## 풀 시즌 덱 슬라이드 개수: **44 (표준)**

이보다 줄어들면 시즌이 *비어 있다*는 신호. 이보다 늘어나면 *패딩이 들어갔다*는 신호. 슬라이드 개수가 50을 초과하면 빈 플레이스홀더를 제거하거나 슬라이드를 통합하세요.

## 임베드 정책 (슬라이드별)

각 "embed" 슬라이드에 대해:

1. 소스 산출물의 `index.html`을 프로젝트 폴더에서 읽으세요.
2. `<main>` 내부 콘텐츠를 추출 (전체 `<main>` 안의 내용).
3. `<section class="slide slide--embed" data-source="<skill-name>">` 으로 래핑.
4. 소스의 `<style>`을 래퍼 클래스로 스코프 (빌드 단계 또는 셀렉터 프리픽스 `.slide[data-source="<skill-name>"]`).
5. 슬라이드 푸터에 attribution chip 추가:
   `<div class="slide-attribution">via <code>fashion-styling-board</code></div>`

소스 산출물이 존재하지 않을 때, `layouts.md`의 **플레이스홀더 슬라이드** 템플릿을 사용하세요 (어떤 모듈이 빠졌는지 + 다음에 실행할 권장 스킬 명시).
